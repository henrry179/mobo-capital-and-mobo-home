生命体征实验室（本地预览占位）

真实的 Streamlit 实验室（Z-Score 标准化 + Lead-Lag 滞后回归）需要 PostgreSQL 中的 archive.v_weekly_life_analytics 视图与 numpy / pandas / psycopg2 运行时，因此只在 Docker 全栈 形态下可用。

四个模块（上线后即为实时数据）
  • ① 多维自律与状态指标 Z-Score 标准化趋势叠加
  • ② Lead-Lag 跨周滞后交叉相关检验（运动 → 精力传导）
  • ③ 52 周读数热力图（阅读 / 训练 / 睡眠 / 体重）
  • ④ 资产容量与冷热分层统计
如何启用真实实验室
  1. 安装 Docker Desktop（或 Linux + Docker Engine 24+）
  2. 按 docs/05-运维与灾备/本地开发与部署.md 执行 L0–L2
  3. 访问 http://lab.localhost/（本地覆盖）或 http://127.0.0.1:8501/（直连）
