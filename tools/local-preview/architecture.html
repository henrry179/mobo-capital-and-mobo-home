莫伯双站 · 本地预览控制台

当前以 零依赖预览模式 运行（无 Docker / 无 PostgreSQL）：两个静态门户按生产同构的路由、 鉴权与缓存策略分发静态文件与预生成 JSON 数据包。购买服务器后，将同一套 sites/、 deploy/、docker-compose.yml 迁到云端即可切换为全栈形态。

API 模式：OpenAI-compatible 双库四 Schema：intel / capital / n8n / archive 红线：物理脱敏 + 人工终审 ADR-0010 本地优先
