## 4. 前端 / 门户模块规格（从规划抽取）

### 4.1 莫伯资本（总册 §6 + 同步记录 + 现网栏目名）

| 导航/模块标题 | 规划意图 | 主要数据/表 |
|---|---|---|
| 总览 Overview | Hero、研究 OS（年季月周日）、导师坐标、精选 Memo 预览、策略矩阵预览 | 部分硬编码 + JSON 合并 |
| 宏观智库 /memo | MoBo's Memo · `macro_theses` | `public-data.json` → `macro_theses` |
| 策略与复盘 /strategies | Alpha Lab · playbooks + 战役表 | playbooks 多在页内常量；`trade_reviews` 可被 JSON 覆盖 |
| 基金孵化蓝图 /incubation | 三阶段 + 里程碑 + 治理文档 + Bot 军团 | 页内数据为主；库有 milestones/gov 表 |
| 量化终端 /terminal | Z-Score、IV/Skew、敞口/HWM | `terminal-snapshot.json` + 页内占位 |
| 自媒体引擎 /media-ops | 1+3 预览（web/微信/雪球/X） | 页内 `mediaPreviews`；库有 `capital_publications` |

**内容吸收来源（同步记录）**：系统级提示词全集、Axe Bot 军团手册、L1 宏观文、生态全景总图、人物库名录等——已写入 HTML 叙事；**非**独立 UI 规格书。

### 4.2 莫伯之家

| 导航/模块标题 | 规划意图 | 主要数据 |
|---|---|---|
| 成长篇章 | 深圳→北京→上海→湖北归航时间线 | `timeline_stories`（`life_chapter` 筛选键） |
| 人生罗盘 | 三线融合 + 认知 OS + 导师 | 页内硬编码为主；源自生态总图/认知报告 |
| 影像画廊 | OSS 冷热 + 800px WebP 缩略 | `gallery_assets` |
| 藏书馆 | 跨学科阅读 | `reading_library` |
| 自律看板 | 周度生命体征 | Streamlit `lab` + 库视图；门户有看板区块 |

区块：KPI、入口矩阵、运行时、投研风控、内容流水线、个人档案、任务与质量门、运维命令复制、成本红线、架构红线。
