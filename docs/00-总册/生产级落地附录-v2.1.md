## 3. 五条不可逾越的架构红线 (Architectural Redlines)

### 红线一：2C4G 内存硬限流与零冗余守护进程

* 全栈严格维持 **6 个容器**，常驻总内存控制在 **1.46GB** 以内，严禁引入 Elasticsearch、Redis 集群、GitLab 或额外的 Node.js/Python 常驻 Web 后端：
1. `mobo-caddy`：`mem_limit: 80m`
2. `mobo-postgres`（pgvector:pg16）：`mem_limit: 600m`（`shared_buffers=128MB`）
3. `mobobrain-pkm`（思源笔记）：`mem_limit: 300m`
4. `mobobrain-n8n`：`mem_limit: 350m`（强制 `EXECUTIONS_PROCESS=main`，严禁开启 queue/worker 模式）
5. `archive-dashboard`（Streamlit）：`mem_limit: 200m`（仅用 `numpy` + `pandas`，严禁引入 `scipy`/`scikit-learn`）
6. `mobo-restic-backup`：`mem_limit: 150m`


* `MoBoCapital.com` 与 `MoBoHome.com` 的前台展示层一律采用 **静态 HTML + `mobo_cli.py` 预生成静态 JSON** 架构，由 `mobo-caddy` 直接提供文件分发，服务端额外内存开销为 **0 MB**。

### 红线二：PostgreSQL 双库物理级权限隔离

* `user_mobobrain` 仅能读写 `db_mobobrain`（含 `04-mobocapital-schema.sql` 中的 `macro_theses`、`strategy_playbooks`、`trade_reviews`、`fund_incubation_milestones`、`fund_governance_docs`、`capital_publications`、`media_channel_metrics`）。
* `user_archive` 仅能读写 `db_archive`（含 `02-archive-schema.sql` 中的 `timeline_events`、`entity_links`、`reading_items`、`reading_logs`、`fitness_workouts`、`fitness_biometrics`、`project_retrospectives`、`archive_assets`）。
* 严禁跨库建立 Foreign Data Wrapper (FDW) 或使用超级用户 `postgres` 运行业务应用。

### 红线三：OSS 双桶隔离、内网免流与冷热分层防破产规则

* ECS 容器内部访问阿里云 OSS 必须使用 `-internal` 内网 Endpoint（`oss-cn-hangzhou-internal.aliyuncs.com`），实现内网上传、下载与 Restic 备份 **0 流量费**。
* 所有上传至私有桶 `mobo-archive-private-hz` 的文件必须严格匹配生命周期前缀：
* `photo/YYYY/MM/`（30天转 IA，180天转 Archive）
* `video/YYYY/MM/`（90天直转 Archive）
* `scan_doc/YYYY/MM/` 与 `blotters/YYYY/MM/`（30天转 IA，180天转 Archive）
* `thumbnails/...`（永久保持 Standard 标准存储，供前端日常列表秒开，严禁前端直接高频请求已归档的冷原件导致高额取回费）。



### 红线四：公私域物理级脱敏与三级访问权限控制 (`PUBLIC` / `LP_PROSPECT` / `INTERNAL`)

* `mobo_cli.py` 在生成 `sites/mobocapital/data/public-data.json` 时，必须在 Python 字典层 **物理删除** `private_blotter_oss_key`、`signed_blotter_url` 字段，并剔除所有 `visibility = 'INTERNAL'` 的记录。
* `mobo_cli.py` 在生成 `sites/mobohome/data/public-home-data.json` 时，必须 **物理剔除** 所有 `is_sensitive = TRUE` 的事件、复盘与私密照片/视频记录。
* 存放全量数据与 OSS 临时签名链接的 `/internal/*` 路径，必须在 `Caddyfile` 中配置强制 `basicauth` 认证，严禁裸奔暴露在公网。

### 红线五：境内/境外双轨内容合规风控

* n8n 工作流 #2 在合成《MoBo's Memo》四端内容时，针对境内平台（微信公众号 `wechat_html`、雪球 `xueqiu_markdown`）必须自动脱敏具体买卖点位与绝对收益承诺，转化为客观宏观因子与波动率复盘，并强制追加合规免责声明；所有发布动作必须经过 **人工终审阀门（HITL Gate）** 批准后方可执行。

### 三、 立即补齐 P0 核心交付物 #2：莫伯资本 NAV 高水位估值与风控熔断触发器 (`05-mobocapital-nav-and-triggers.sql`)

对冲基金运营的核心在于 **净值核算（NAV Accounting）、高水位法业绩报酬计提（High-Water Mark）与强制回撤控制（Drawdown Circuit Breaker）**。

这段 SQL 为 `db_mobobrain` 补齐了最后一块核心拼图：每当你通过 `mobo_cli.py trade` 录入或平仓一笔交易，**PostgreSQL 底层触发器会自动计算最新组合模拟净值、历史最高水位（HWM）、当前回撤幅度，并在触及风控阈值时自动把组合状态切换为预警或强制减仓模式**，同时预置你的四大核心策略标准手册（`strategy_playbooks`）与宏观主线（`macro_theses`）。

```sql
-- ============================================================================
-- 文件路径: /opt/mobo-stack/init-scripts/05-mobocapital-nav-and-triggers.sql
-- 目标数据库: db_mobobrain (执行角色: user_mobobrain)
-- 核心功能: 
--   1. 建立对冲基金模拟份额净值 (NAV)、高水位线 (HWM) 与回撤风控熔断台账
--   2. 建立实战交易平仓后自动更新 NAV 与检测风控阈值的触发器 (零人工双写)
--   3. 预置莫伯资本四大核心策略手册 (Playbooks) 与宏观主线初始数据
-- ============================================================================

\connect db_mobobrain user_mobobrain;

-- ----------------------------------------------------------------------------
-- 1. 莫伯资本组合净值 (NAV) 与高水位风控台账表 (portfolio_nav_ledger)
-- 结合中级会计准则与私募基金高水位法 (High-Water Mark) 核算逻辑
-- ----------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS portfolio_nav_ledger (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    valuation_date DATE UNIQUE NOT NULL DEFAULT CURRENT_DATE,
    trigger_trade_code VARCHAR(40),                      -- 触发本次净值更新的战役编号
    
    -- 份额净值与高水位核算 (初始基准净值 = 1.0000)
    gross_nav NUMERIC(10,4) NOT NULL DEFAULT 1.0000,     -- 费前累计单位净值
    high_water_mark NUMERIC(10,4) NOT NULL DEFAULT 1.0000,-- 历史最高水位线 (HWM)
    accrued_perf_fee_nav NUMERIC(10,4) DEFAULT 0.0000,   -- 按 20% 超额计提的模拟业绩报酬扣减额
    net_nav NUMERIC(10,4) NOT NULL DEFAULT 1.0000,       -- 费后单位净值 (LP 真实体验净值)
    
    -- 风险与回撤监控指标
    current_drawdown_pct NUMERIC(6,2) NOT NULL DEFAULT 0.00, -- 相对 HWM 的当前回撤百分比 (如 -3.45)
    cumulative_r_multiple NUMERIC(8,2) NOT NULL DEFAULT 0.00,-- 累计实现总 R 乘数
    
    -- 三级风控委员会状态机:
    -- 'NORMAL' (回撤 < 5%: 正常仓位上限)
    -- 'YELLOW_ALERT' (回撤 5%~8%: 单笔风险上限减半至 0.75% NAV)
    -- 'RED_CIRCUIT_BREAKER' (回撤 >= 8%: 触发投委会熔断，强制降仓并禁止新开买方期权)
    risk_regime_status VARCHAR(24) NOT NULL DEFAULT 'NORMAL'
        CHECK (risk_regime_status IN ('NORMAL', 'YELLOW_ALERT', 'RED_CIRCUIT_BREAKER')),
    risk_action_note TEXT,
    created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);

-- 插入基金孵化初始基准净值点 (1.0000)
INSERT INTO portfolio_nav_ledger (
    valuation_date, trigger_trade_code, gross_nav, high_water_mark, net_nav, 
    current_drawdown_pct, cumulative_r_multiple, risk_regime_status, risk_action_note
) VALUES (
    '2026-01-01', 'GENESIS-INIT', 1.0000, 1.0000, 1.0000, 
    0.00, 0.00, 'NORMAL', '莫伯资本 Phase 1 实盘孵化组合初始基准净值 (NAV = 1.0000)'
) ON CONFLICT (valuation_date) DO NOTHING;

-- ----------------------------------------------------------------------------
-- 2. 自动化触发器：当 trade_reviews 平仓或更新时，自动核算最新 NAV 与回撤熔断状态
-- ----------------------------------------------------------------------------
CREATE OR REPLACE FUNCTION fn_update_nav_on_trade_close()
RETURNS TRIGGER AS $$
DECLARE
    v_prev_nav NUMERIC(10,4);
    v_prev_hwm NUMERIC(10,4);
    v_total_r NUMERIC(8,2);
    v_delta_nav NUMERIC(10,4);
    v_new_gross_nav NUMERIC(10,4);
    v_new_hwm NUMERIC(10,4);
    v_perf_fee NUMERIC(10,4);
    v_new_net_nav NUMERIC(10,4);
    v_drawdown_pct NUMERIC(6,2);
    v_risk_status VARCHAR(24);
    v_risk_note TEXT;
BEGIN
    -- 仅在交易状态为 CLOSED 或 STOPPED_OUT 且填写了 portfolio_impact_bps 时触发核算
    IF NEW.trade_status IN ('CLOSED', 'STOPPED_OUT') AND NEW.portfolio_impact_bps IS NOT NULL THEN
        
        -- 获取最近一期的净值与高水位线
        SELECT gross_nav, high_water_mark 
        INTO v_prev_nav, v_prev_hwm
        FROM portfolio_nav_ledger
        ORDER BY valuation_date DESC, created_at DESC
        LIMIT 1;

        v_prev_nav := COALESCE(v_prev_nav, 1.0000);
        v_prev_hwm := COALESCE(v_prev_hwm, 1.0000);

        -- 计算组合累计实现 R 乘数
        SELECT COALESCE(SUM(realized_r_multiple), 0.00)
        INTO v_total_r
        FROM trade_reviews
        WHERE trade_status IN ('CLOSED', 'STOPPED_OUT');

        -- 根据所有已平仓战役的累计基点贡献 (10000 bps = 1.0000) 计算最新费前净值
        SELECT 1.0000 + COALESCE(SUM(portfolio_impact_bps), 0) / 10000.0
        INTO v_new_gross_nav
        FROM trade_reviews
        WHERE trade_status IN ('CLOSED', 'STOPPED_OUT');

        -- 更新历史高水位线 (High-Water Mark)
        v_new_hwm := GREATEST(v_prev_hwm, v_new_gross_nav);

        -- 高水位法模拟计提 20% 超额业绩报酬 (仅对超过 1.0000 的正收益部分估算)
        IF v_new_gross_nav > 1.0000 THEN
            v_perf_fee := ROUND((v_new_gross_nav - 1.0000) * 0.20, 4);
        ELSE
            v_perf_fee := 0.0000;
        END IF;

        v_new_net_nav := v_new_gross_nav - v_perf_fee;

        -- 计算当前相对历史最高水位线的回撤百分比 (Drawdown %)
        v_drawdown_pct := ROUND(((v_new_gross_nav - v_new_hwm) / v_new_hwm) * 100.0, 2);

        -- 判定三级风控熔断状态机
        IF v_drawdown_pct <= -8.00 THEN
            v_risk_status := 'RED_CIRCUIT_BREAKER';
            v_risk_note := '【红色风控熔断】组合回撤已触及 -8% 警戒线！强制将总敞口压降至 25% 以内，禁止新开买方期权头寸，必须完成书面复盘。';
        ELSIF v_drawdown_pct <= -5.00 THEN
            v_risk_status := 'YELLOW_ALERT';
            v_risk_note := '【黄色回撤预警】组合回撤超过 -5%，自动触发“慢就是快”保护机制：单笔最大风险敞口由 1.50% 下调至 0.75% NAV。';
        ELSE
            v_risk_status := 'NORMAL';
            v_risk_note := '组合净值运行稳健，回撤处于安全垫范围内，维持标准风险预算（单笔 ≤ 1.50% NAV）。';
        END IF;

        -- 幂等写入当日净值台账
```

### 一、 核心量化计算模型与策略映射逻辑

采集器在入库前通过纯 `NumPy` 自动完成三项核心衍生指标计算：

1. **宏观先行指标滚动 Z-Score（标准化偏离度）**
针对制造业 PMI（新订单减产成品库存剪刀差）、社融与 M1-M2 剪刀差、美国 ISM 新订单等序列，按过去 $W$ 期（月度数据取 $W=24$，日频利差取 $W=252$）计算滚动标准化得分：

$$Z_t = \frac{X_t - \mu_W}{\sigma_W}$$



当 $Z_t \ge 0.8\sigma$ 时标记为 `EXPANSION`（扩张共振），当 $Z_t \le -0.8\sigma$ 时标记为 `CONTRACTION`（收缩防御）。
2. **隐含波动率年化分位（IV Rank 与 IV Percentile）**
采集 30 日平值隐含波动率 $\text{IV}_{30\text{d}}$ 与 30 日历史实现波动率 $\text{HV}_{30\text{d}}$，计算过去 252 个交易日的波动率等级（$\text{IVR}$）、波动率分位数（$\text{IVP}$）以及波动率风险溢价（$\text{VRP}$）：

$$\text{IVR}_t = 100 \times \frac{\text{IV}_t - \text{IV}_{\min, 252}}{\text{IV}_{\max, 252} - \text{IV}_{\min, 252}}, \quad \text{IVP}_t = \frac{1}{252} \sum_{i=1}^{252} \mathbb{I}(\text{IV}_i \le \text{IV}_t) \times 100$$


$$\text{VRP}_t = \text{IV}_{30\text{d}, t} - \text{HV}_{30\text{d}, t}$$


3. **期权波动率曲面自动策略映射（Playbook Router）**
根据 $\text{IVP}_t$ 与 25-Delta 认沽-认购偏度（$\text{Skew}_{25\Delta} = \text{IV}_{\text{25d Put}} - \text{IV}_{\text{25d Call}}$）自动生成 `/terminal` 栏目的策略偏好建议：
* **低波买方区**（$\text{IVP}_t \le 35\%$ 且 $\text{Skew}_{25\Delta}$ 平坦）：推荐 `Bull Call / Bear Put Spread`（垂直价差）或 `Long Diagonal`。
* **高偏度套利区**（$\text{IVP}_t \ge 55\%$ 且 $\text{Skew}_{25\Delta} \ge 4.0\%$）：推荐 `1x2 Put Ratio Spread`（认沽比例价差，利用昂贵的虚值 Put 补贴权利金）。
* **中枢震荡区**（$35\% \lt \text{IVP}_t \lt 55\%$）：推荐 `Calendar Spread`（日历价差）赚取近月 Theta 衰减。

### 三、 每日自动采集与终端同步脚本 (`/opt/mobo-stack/scripts/macro_iv_collector.py`)

该脚本具备**三层容错与双模式录入能力**：

1. **自动行情与波动率抓取**：通过轻量级 HTTP 接口拉取沪深300 ETF（`510300`）、恒生科技、标普500（`SPY`）、黄金（`GLD`）、美债10Y收益率（`^TNX`）、VIX 恐慌指数与离岸人民币汇率（`USDCNH`）的日频序列，自动计算 30 日历史波动率（$\text{HV}_{30\text{d}}$）、1 年期波动率分位与 Z-Score。

```python
# 2. 纯 NumPy 量化指标计算内核 (Z-Score / HV30 / IV Rank / Strategy Router)
# ============================================================================
def calc_rolling_zscore(series_values: list, current_val: float) -> float:
    """使用纯 NumPy 计算当前读数在历史窗口中的 Z-Score 标准差偏离度"""
    arr = np.array(series_values + [current_val], dtype=np.float64)
    if len(arr) < 3:
        return 0.0
    mean = np.mean(arr)
    std = np.std(arr, ddof=1)
    if std < 1e-8:
        return 0.0
    return round(float((current_val - mean) / std), 2)


def classify_macro_regime(z_score: float) -> str:
    """根据 Z-Score 自动映射宏观周期状态标签"""
    if z_score >= 0.80:
        return "EXPANSION"
    elif z_score >= 0.20:
        return "IMPROVING"
    elif z_score <= -0.80:
        return "CONTRACTION"
    elif z_score <= -0.20:
        return "BOTTOMING"
    return "NEUTRAL"


def calc_iv_rank_and_percentile(iv_history: list, current_iv: float) -> tuple:
    """
    计算过去 252 个交易日的 IV Rank (IVR) 与 IV Percentile (IVP)
    返回: (iv_rank, iv_percentile)
    """
    arr = np.array(iv_history + [current_iv], dtype=np.float64)
    if len(arr) < 5:
        return 50.0, 50.0

    iv_min = float(np.min(arr))
    iv_max = float(np.max(arr))
    if iv_max - iv_min < 1e-5:
        iv_rank = 50.0
    else:
        iv_rank = round(100.0 * (current_iv - iv_min) / (iv_max - iv_min), 1)

    iv_pct = round(float(np.sum(arr <= current_iv) / len(arr) * 100.0), 1)
    return np.clip(iv_rank, 0.0, 100.0), np.clip(iv_pct, 0.0, 100.0)


def recommend_option_structure(iv_pct: float, skew_25d: float) -> str:
    """根据隐含波动率分位数与 25D Put-Call Skew 自动匹配莫伯资本策略结构"""
    if iv_pct <= 35.0:
        if skew_25d <= 0.0:
            return "Long Bull Call Spread"
        return "Long Diagonal / Straddle"
    elif iv_pct >= 60.0:
        if skew_25d >= 3.5:
            return "1x2 Put Ratio Spread"
        return "Iron Condor / Short Strangle"
    else:
        if skew_25d <= -1.0:
            return "Call Ratio Spread"
        return "Calendar Spread"

def fetch_json_url(url: str, timeout: int = 8) -> dict:
    req = urllib.request.Request(
        url,
        headers={
            "User-Agent": "Mozilla/5.0 (X11; Linux x86_64) MoBoCapitalQuantTerminal/2.1"
        },
    )
    with urllib.request.urlopen(req, timeout=timeout) as resp:
        return json.loads(resp.read().decode("utf-8"))


def fetch_yahoo_chart_metrics(symbol: str) -> dict:
    """
    从公开日线接口拉取过去 1 年日频收盘价，计算最新价、涨跌幅与 30D 历史年化波动率 (HV30)
    若网络受限则返回 None，由调用方平滑回退至数据库历史值
    """
    try:
        url = f"https://query1.finance.yahoo.com/v8/finance/chart/{symbol}?range=1y&interval=1d"
        data = fetch_json_url(url, timeout=6)
        result = data["chart"]["result"][0]
        closes = [
            c for c in result["indicators"]["quote"][0]["close"] if c is not None
        ]
        if len(closes) < 35:
            return None

        spot = round(float(closes[-1]), 4)
        prev = float(closes[-2])
        chg_pct = round((spot - prev) / prev * 100.0, 2)

        # 计算最近 30 个交易日的对数收益率年化标准差 (HV30)
        recent_31 = np.array(closes[-31:], dtype=np.float64)
        log_returns = np.diff(np.log(recent_31))
        hv_30d = round(float(np.std(log_returns, ddof=1) * np.sqrt(252) * 100.0), 2)

        return {"spot": spot, "chg_pct": chg_pct, "hv_30d": hv_30d}
    except Exception:

def run_daily_collection():

    today_str = str(date.today())
    conn = get_capital_db_conn()

    try:
        with conn:
            with conn.cursor(cursor_factory=RealDictCursor) as cur:
                # 1. 尝试在线更新 VIX、美债10Y与离岸人民币日频读数
                vix_live = fetch_yahoo_chart_metrics("^VIX")
                tnx_live = fetch_yahoo_chart_metrics("^TNX")
                cnh_live = fetch_yahoo_chart_metrics("CNH=X")

                for item in DEFAULT_MACRO_BASELINES:
                    code = item["code"]
                    val = item["val"]
                    prev = item["prev"]

                    if code == "VIX_INDEX" and vix_live:
                        val = vix_live["spot"]
                    elif code == "US10Y_YIELD" and tnx_live:
                        val = tnx_live["spot"]
                    elif code == "USDCNH_SPOT" and cnh_live:
                        val = cnh_live["spot"]

                    # 从数据库读取历史序列以计算真实滚动 Z-Score
                    cur.execute(
                        """
                        SELECT raw_value FROM macro_indicator_series
                        WHERE indicator_code = %s AND obs_date < %s
                        ORDER BY obs_date DESC LIMIT 24;
                        """,
                        (code, today_str),
                    )
                    db_hist = [float(r["raw_value"]) for r in cur.fetchall()]
                    hist_series = db_hist if len(db_hist) >= 5 else item["history"]

                    z_score = calc_rolling_zscore(hist_series, val)
                    regime = classify_macro_regime(z_score)
                    chg = round(val - prev, 4)

                    cur.execute(
                        """
                        INSERT INTO macro_indicator_series (
                            indicator_code, indicator_name, region, frequency,
                            obs_date, raw_value, prev_value, change_val, z_score, regime_tag, updated_at

                            raw_value = EXCLUDED.raw_value,

                            change_val = EXCLUDED.change_val,
                            z_score = EXCLUDED.z_score,

                            code,
                            item["name"],
                            item["region"],
```

在 `mobocapital-portal.html` 底部的 `<script>` 中加入以下 `loadTerminalSnapshot()` 函数，并在 `DOMContentLoaded` 中调用。它会直接读取 `/data/terminal-snapshot.json`，**自动刷新页面最顶部的实时行情滚动条（Regime Bar）以及第四栏目 `/terminal` 的宏观 Z-Score 进度条与期权波动率曲面表**：

```javascript
async function loadTerminalSnapshot() {
  try {
    const res = await fetch('/data/terminal-snapshot.json', { cache: 'no-store' });
    if (!res.ok) return;
    const data = await res.json();

    // 1. 动态更新 /terminal 期权隐含波动率曲面表
    if (data.options_vol_surface && data.options_vol_surface.length) {
      const tbody = document.querySelector('#sec-terminal table tbody');
      if (tbody) {
        tbody.innerHTML = data.options_vol_surface.map(v => {
          const pctColor = v.iv_percentile_1y <= 35 ? 'text-emerald-400' : (v.iv_percentile_1y >= 65 ? 'text-rose-400' : 'text-amber-400');
          const skewStr = v.skew_25d > 0 ? `+${v.skew_25d}%` : `${v.skew_25d}%`;
          return `
            <tr>
              <td class="py-2.5 text-white font-semibold">${v.asset_name}</td>
              <td class="py-2.5">${v.iv_30d}%</td>
              <td class="py-2.5 ${pctColor}">${v.iv_percentile_1y}%</td>
              <td class="py-2.5">${skewStr}</td>
              <td class="py-2.5 text-right text-gold-400">${v.recommended_structure}</td>
            </tr>
          `;
        }).join('');
      }
    }
  } catch (e) {
    console.log('[Quant Terminal] 本地预览模式，保持默认基准面板。');
  }
}
```
