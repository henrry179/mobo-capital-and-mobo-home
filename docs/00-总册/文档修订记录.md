## v1.1 变更明细

### 架构

- 网站 A 改为 `www` 公开静态站 + `kb` 受保护思源 + `n8n` 受保护后台 + `admin` 操作台。
- n8n 从 `/n8n/` 子路径改为 `n8n.` 子域，补齐 `N8N_HOST`、`WEBHOOK_URL`、`N8N_PROXY_HOPS`。
- 明确单实例双库 + Schema 隔离：`db_mobobrain(intel,n8n)` + `db_archive(archive)`。

### 数据库

- 新增 `intel.sources/articles_vault/content_drafts/ingestion_runs/llm_usage`。
- 新增 `sources`、`content_drafts` 状态机与索引。
- 补 `updated_at` 触发器、HNSW、`pg_trgm`、只读/备份账号。
- 补迁移机制，initdb 仅负责首次空库。

### 部署与运维

- 备份镜像改为自带 `restic` + `postgresql-client`。
- 数据库备份改为 `pg_dump -Fc`，不直接备份运行中的 `pg_data`。
- 补 `disaster-recovery.sh`、`restore-drill.sh`、`host-hardening.sh`、`smoke-test.sh`。
- 补监控、日志轮转、SSH 加固、ufw、fail2ban。
- 补 T-14/T-15/T-16，闭合“16 步”。

### 安全与合规

- 网站 A 核心库不再公网直出。
- RAM 子账号最小权限，不使用 `AliyunOSSFullAccess`。
- 补 ICP 材料、隐私数据分类、密钥清单。
- 补 OSS 最低存储期/取回费/防盗链注意事项。
