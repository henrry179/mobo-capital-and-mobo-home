# 术语表

| 术语 | 说明 |
|---|---|
| **网站 A / MoBoBrain** | 知识库与内容自动化中枢，思源 + n8n + PostgreSQL |
| **网站 B / Archive** | Wolfram 式计算型个人数字档案，Streamlit + PostgreSQL |
| **双站** | 两个独立网站共用一台主机与一套 PostgreSQL 实例，但域名、容器、数据库/Schema、鉴权独立 |
| **Schema 隔离** | 同一 PostgreSQL 实例内用不同 Schema 隔离业务域；不是独立实例 |
| **冷热分层** | 标准存储（热）、低频 IA（温）、归档 Archive（冷）三级 |
| **RPO** | Recovery Point Objective，可接受的数据丢失时间窗；本项目 24h |
| **RTO** | Recovery Time Objective，恢复业务所需时间；本项目分级 |
| **Restic** | 开源加密备份工具，支持 S3 兼容对象存储 |
| **pgvector** | PostgreSQL 向量扩展，支持 `vector` 类型与 HNSW/IVFFlat 索引 |
| **HNSW** | 近似最近邻图索引，适合低延迟语义检索 |
| **pg_trgm** | PostgreSQL 三元组模糊匹配扩展，用于中文标题/摘要降级检索 |
| **zhparser** | 中文分词扩展；需自定义镜像，本期未默认启用 |
| **Lead-Lag** | 滞后相关/回归，检验 X(t) 是否领先驱动 Y(t+lag) |
| **Z-Score** | 标准化分数，用于跨指标比较周度节律 |
| **BasicAuth** | HTTP Basic 认证；必须配合 HTTPS 使用 |
| **Bcrypt** | 密码哈希算法；Caddy 使用 `caddy hash-password` 生成 |
| **ADR** | Architecture Decision Record，架构决策记录 |
| **DoD** | Definition of Done，完成定义 |
| **Restic 救命胶囊** | `.env`、恢复脚本、Restic 密码、n8n 加密密钥的离线副本 |
| **ICP** | 中国大陆网站备案；个人性质备案对网站名称有敏感词限制 |
| **OSS** | 阿里云对象存储；本项目使用公开图床 Bucket + 私有档案 Bucket |
| **IA / Archive** | OSS 低频访问 / 归档存储类型；有最低存储期与取回费 |
| **SplitInBatches** | n8n 节点，分批串行处理，防止 Node.js OOM |
| **Jina Reader** | 将网页提纯为 Markdown 的阅读器服务 |
| **Content Vault** | `intel.articles_vault`，采集文章主库 |
| **Draft Studio** | `intel.content_drafts`，多平台草稿箱 |
