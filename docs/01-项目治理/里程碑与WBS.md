# 里程碑与 WBS（16 步实施计划）

> 状态：`未开始` / `进行中` / `完成` / `阻塞`；`完成（待验证）` = 交付物已写入，但尚未在 Docker/Python 环境执行验证（本机缺 Docker，统一在 T-08/T-10 执行）。本表是项目唯一任务清单，配套仪表板可按此同步。

## 1. 阶段总览

| Phase | 名称 | 预计 | 关键产出 | 退出条件 |
|---|---|---:|---|---|
| 0 | 立项基线 | 0.5–1d | 目录、总册、ADR、风险登记、`.env.example` | 4 个关键决策确认 |
| 1 | 架构与数据设计 | 1–2d | 架构图、数据字典、成本台账 | 设计评审通过 |
| 2 | 数据库 | 2–3d | `01~06.sql`、触发器、索引、账号、迁移 | 本地初始化 + Smoke Test |
| 3 | 应用与工具 | 3–4d | CLI、Dashboard、Console | 单测 + 手工验收 |
| 4 | 部署与灾备 | 2–3d | Compose、Caddy、备份、DR、加固 | 本地全栈 + 恢复演练 |
| 5 | 自动化与内容闭环 | 2–3d | n8n #1/#2、思源、公开站 | 端到端跑通 |
| 6 | 上线与验收 | 1–2d | 云上双站、监控、验收 | 验收清单全绿 |

**总计**：约 12–16 个工作日；业余推进 3–4 周。

## 2. 关键路径

```text
Phase 0 → 服务器/OSS/域名（T-01~T-04）
        → 主机加固（T-05~T-07）
        → 数据库（T-08）→ 应用（T-09）→ 全栈（T-10）
        → DNS/HTTPS（T-11）→ n8n（T-12）→ 备份（T-13）
        → 监控（T-14）→ 恢复演练（T-15）→ 验收（T-16）
```

ICP 审核 5–10 个工作日，**不是关键路径**：T-05~T-10 可在等待期完成，T-11 等备案通过后执行。
