## 2. 高优先级风险（Top 5）

1. **R-01 OOM**：2C4G 的最大系统性风险。任何“再加一个容器”的想法都要先算内存。
2. **R-02 OSS 账单**：对象存储的流量费远高于容量费；必须内网 + 防盗链 + 熔断。
3. **R-04 备份不可恢复**：没有演练的备份等于没有备份。
4. **R-06 后台入侵**：网站 B 是个人隐私数据，BasicAuth 必须强密码 + HTTPS + 监控。
5. **R-08 中文检索**：不要被 `to_tsvector('simple')` 迷惑，中文需要分词或降级方案。
