# ADR-0007：双主域拓扑与静态门户 + 三级可见性

- **状态**：已接受（待域名最终确认）
- **日期**：2026-10-21
- **决策人**：莫伯
- **相关**：ADR-0002（域名拓扑与公开静态站）、CLAUDE.md 红线一/红线四

## 背景

v1.1 采用"一个主域名 + `www`/`kb`/`n8n`/`archive`/`admin` 五个子域"，网站 A（知识库/自媒体）与网站 B（个人档案）共用同一品牌域。随着网站 A 定位升级为**莫伯资本（投研/基金孵化/财经自媒体）**、网站 B 升级为**莫伯之家（个人数字档案）**，两条业务线的内容气质、访问对象与合规压力已经完全不同：

- 莫伯资本需要 LP 准投资人级别的二级可见性与境内平台合规脱敏；
- 莫伯之家的公域展示只应包含人生叙事、影像与藏书，不应与投研内容混在同一个品牌域下。

## 决策

1. **双主域**：`mobocapital.com`（网站 A）与 `mobohome.com`（网站 B），各自可独立备案、独立签发证书、独立统计。
2. **生产力子域挂在网站 A 下**：`kb`（思源）、`n8n`（自动化）、`lab`（生命体征实验室）、`admin`（操作台）。
3. **前台一律静态化**：`sites/<站>/index.html` + 预生成 JSON；Caddy 只读分发，服务端额外内存 0MB（红线一）。
4. **三级可见性**取代"公开/私密"二值：
   - `PUBLIC`：全网可见；
   - `LP_PROSPECT`：准投资人可见（累计 R 乘数、净值贡献、风控章程）；
   - `INTERNAL`：内网驾驶舱（全量底稿、交割单签名链接）。
5. **可见性靠物理脱敏实现**：导出公域 JSON 时删除私有字段并剔除 `INTERNAL` / `is_sensitive` 记录，而不是靠前端隐藏或路径保密。

## 理由

- 双主域让两个站可以分别对外叙述、分别备案、分别做合规动作，避免"一个域名里混着个人档案"的舆论与合规风险。
- 静态化把 2C4G 的内存压力降到最低，同时保留了完整交互能力。
- 物理脱敏把风险控制点前移到唯一可控的位置（CLI 写盘前），不依赖多层"隐藏"是否生效。

## 代价与缓解

| 代价 | 缓解 |
|---|---|
| 域名与备案成本翻倍 | 同一主体、同一服务器、同一备案批次提交；两地 ICP 均需 5–10 工作日 |
| 证书与 DNS 条目增加 | Caddy 自动签发，DNS 用 A 记录指向同一 IP |
| 需要 CLI 生成 JSON，静态内容有延迟 | 公域 JSON 缓存 60 秒，CLI 支持定时导出（Cron） |
| 脱敏逻辑写错会造成泄露 | `exporters.audit_payload()` 写盘前自检 + 单元测试 + 归档包只放 BasicAuth 之后 |

## 备选方案

- **单主域 + 路径隔离**（`/capital`、`/home`）：被否。静态资源、WebSocket、书签与分享体验都受影响，且无法分别备案。
- **完全动态渲染**（服务端渲染两站）：被否。2C4G 无法稳定承载两个渲染进程，且违背红线一。
