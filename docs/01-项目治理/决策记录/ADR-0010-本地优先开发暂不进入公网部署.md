# ADR-0010：本地优先开发，暂不进入公网部署

- **状态**：已接受
- **日期**：2026-10-21
- **决策人**：莫伯
- **相关**：ADR-0007（双主域）、TASK_STATE.md T01/T04、风险登记册 D-01/D-07/D-08/D-09

## 背景

原计划的 T01–T16 中，有 4 个环节依赖**外部资源**：

- T01 采购阿里云 ECS、T02 开通 OSS、T04 注册双主域并提交 ICP；
- T12 阶段二需要微信开放平台与 X API 凭证。

当前约束：

1. `mobocapital.com` / `mobohome.com` **均未注册**，ICP 无法启动；
2. 备案审核 5–10 个工作日，且网站名称涉及"资本/投研"类表述存在被驳回风险；
3. 在公网暴露含实盘复盘与个人档案的系统，而域名、密钥、合规流程都未跑通，风险不对称；
4. 本地已具备完整工程基线（01~09 SQL、六容器编排、双域网关、CLI、看板、门户、工作流资产），**不需要云资源也能推进绝大多数工作**。

## 决策

**项目进入"本地优先"阶段（L 阶段）：暂不进入公网部署与上线。**

1. **范围收缩到 L0–L6 本地任务**：
   - L0 本地环境与编排基线（Docker Desktop + Compose + `.env.local`）
   - L1 数据库内核落地验证（01~09 SQL 首次初始化 + `smoke.sql` 全绿）
   - L2 应用与门户本地跑通（看板四模块、CLI 四类新命令、双站门户、静态数据包导出）
   - L3 n8n 双工作流本地联调（工作流 #1/#2/#3，LLM 用测试 Key 或本地桩）
   - L4 备份/灾备本地演练（本地 Restic 仓库 + `restore-drill.sh`）
   - L5 质量门：单测、JSON 校验、Shell 语法、脱敏审计、内存实测
   - L6 公网就绪包（域名/备案/密钥/监控材料**全部备好但不启用**）
2. **云端与公网动作全部挂起**：T01–T04、T11、T13 的公网部分标记 `BLOCKED/暂缓`，不影响 L 阶段推进。
3. **微信/X 保持"只生成 JSON 草稿"**：不接入公众号草稿箱直推、不调用 X 发布 API；工作流 #3 阶段二（发布）节点在本地阶段保持禁用，只保留阶段一（合成 → 写库 → 待审队列）。
4. **预算口径不变**：基础设施 ≤ ¥2,400/年红线保留；LLM 单列 ≤ ¥150/月（本地阶段实际 LLM 支出计入该额度）。
5. **本地不留真数据**：本地只放测试数据与沙盒数据（`seeds/52-week-sandbox.sql`）；真实密钥仍只进密码管理器与服务器 `.env`。

## 理由

| 理由 | 说明 |
|---|---|
| 解除外部阻塞 | 域名与备案是当前最长且不可控的依赖；本地开发不需要它 |
| 风险对称 | 未跑通合规与密钥流程前，不把含实盘与隐私的系统暴露公网 |
| 验证前置 | 容器初始化、触发器、看板、CLI、脱敏导出这些"代码是否真的对"，本就能在本地证伪，不必等上云 |
| 成本 | 本地阶段云端支出为 0，把 ¥2,400 红线留给真正上线后的首年 |
| 可逆 | 公网就绪包（材料、脚本、清单）提前备好，域名到手后按 T-08→T-16 顺序切换即可 |

## 代价与缓解

| 代价 | 缓解 |
|---|---|
| 本地 HTTPS 需自签证书，浏览器告警 | 本地一律用 `http://localhost`（Caddy 关闭自动 HTTPS），生产再切 ACME |
| 域名相关配置无法真实验证 | 用 `localhost` / `*.localhost` 与 hosts 覆盖验证路由与鉴权行为 |
| 微信/X 链路无法端到端 | 阶段一（合成 JSON）可完整验证；发布链路在公网就绪包中做纸面走查 + 单测 |
| 云端 OSS（签名 URL、生命周期）无法验证 | 用本地 MinIO 或 OSS 桶的公共读子集做替代验证；`oss_guard_setup.py` 支持 DRY_RUN |

## 退出条件（进入公网阶段）

同时满足即可解除挂起，按 `TASK_STATE.md` 恢复 T01→T16：

1. 双主域已注册并完成实名；
2. ICP 提交并进入管局审核（网站名称用"莫伯资本 / 莫伯之家"这类中性表述）；
3. 阿里云账号可下单，OSS 双桶就绪；
4. 微信/X 凭证到位（或明确继续只生成草稿）；
5. L 阶段 L5 质量门全绿，且本地 RTO 演练有记录。
