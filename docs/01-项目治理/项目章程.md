# 项目章程

## 1. 项目名称

**莫伯（MoBo）双站系统**  
MoBoBrain 知识库与内容自动化中枢 × Wolfram 式计算型个人数字档案系统

## 2. 背景

当前个人知识、研究资料、阅读记录、运动生理数据、照片视频与复盘分散在多个工具中，缺少统一的时间轴与可计算的分析底座。项目目标是在年度 2,400 元预算内，用一台 2C4G 云主机建立两个逻辑独立、数据可恢复、可长期维护的网站：

- 网站 A：把研究资料采集、提炼、归档、内容生产串成流水线。
- 网站 B：把个人生活数据变成可查询、可回归、可复盘的时间序列档案。

## 3. 项目目标

| 目标 | 衡量标准 |
|---|---|
| 双站上线 | `www/kb/n8n/archive/admin` 五个入口可用；受保护入口未认证 401 |
| 知识库可用 | 思源可创建/编辑/搜索；n8n 采集能自动入库并推送高分文章 |
| 档案可计算 | 时间线、阅读、运动、复盘、资产五类数据可写入；周度看板可展示 |
| 数据可恢复 | Restic 每日备份；staging 恢复对账一致；RTO 有实测记录 |
| 成本可控 | 首年实际支出 ≤2,400 元；预算/流量/余额告警生效 |
| 安全达标 | 无公网数据库；全部后台强认证；密钥不入 Git |

## 4. 范围摘要

**包含**

- 阿里云 2C4G + OSS 双 Bucket + 域名/备案。
- Docker Compose 六容器：Caddy、PostgreSQL、思源、n8n、Streamlit、Restic。
- 网站 B 数据库、触发器、看板、CLI。
- 网站 A 数据库、n8n 两条工作流、思源集成、公开静态站。
- 备份、恢复、监控、安全基线、运维手册。

**不包含**

- 多用户/社区/评论/UGC。
- 微信/雪球/X 自动发布。
- 视频转码、完整 OCR、移动端 App。
- 多活、Kubernetes、商业 SaaS。

详见 `范围与边界.md`。

## 5. 成功标准

1. 16 步部署全部完成，验收清单全绿。
2. 双站连续运行 30 天无 P0 故障；无 OOM、无数据丢失。
3. 备份可恢复，RPO ≤24h；数据库/配置 RTO ≤2h。
4. 首年成本 ≤2,400 元，且至少保留 500 元机动。
5. 运维文档、ADR、密钥清单齐全，后续可独立维护。

## 6. 关键约束

- **硬件**：2C4G，必须 4GB Swap；不能跑 Elasticsearch、双 PostgreSQL 实例、重型 OCR。
- **预算**：2,400 元/年红线；优先 3 年连购/活动价。
- **合规**：大陆服务器 + 域名需 ICP；个人备案名称规避财经/金融/量化等敏感词。
- **时间**：业余推进，预计 3–4 周；ICP 审核 5–10 个工作日可并行部署。
- **单用户**：默认只有莫伯一人使用；不做多租户。

## 7. 假设

- 已有一个阿里云账号，可完成实名/备案。
- 有一个主域名，或愿意注册一个。
- 有可用的 LLM/Embedding API（OpenAI-compatible、Qwen、DeepSeek 等）。
- 本地有 Docker Desktop 或可用的 Linux 开发环境。
- 网站 B 的数据以个人隐私为主，默认全私有。

## 9. 治理方式

- **决策**：架构级变更写 ADR；数据库变更走 migrations；密钥变更更新清单。
- **节奏**：按 Phase 0–6 推进；每个 Phase 结束做一次 Demo/验收。
- **记录**：`docs/00-总册/文档修订记录.md`、`docs/01-项目治理/风险登记册.md`。
- **质量门**：SQL Smoke Test、Compose config、CLI 单测、恢复演练、验收清单。
