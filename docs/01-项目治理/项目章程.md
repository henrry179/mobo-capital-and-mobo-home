# 项目章程

## 1. 项目名称

**莫伯（MoBo）双站系统**  
MoBoBrain 知识库与内容自动化中枢 × Wolfram 式计算型个人数字档案系统

## 2. 背景

当前个人知识、研究资料、阅读记录、运动生理数据、照片视频与复盘分散在多个工具中，缺少统一的时间轴与可计算的分析底座；同时，投研笔记、实盘复盘与自媒体内容又需要一个能长期沉淀的载体。项目目标是在年度 2,400 元基础设施预算内，用一台 2C4G 云主机建立两个逻辑独立、数据可恢复、可长期维护的网站：

- **网站 A：莫伯资本（MoBoCapital.com）** —— 职业纵深、全球宏观投研智库与独立对冲基金孵化平台；沉淀 ITPM 宏观推演、期权波动率策略、实战复盘归因、基金三阶段孵化蓝图与《MoBo's Memo》财经自媒体"1+3"矩阵。
- **网站 B：莫伯之家（MoBoHome.com）** —— 个人主权数字档案馆与温润生命叙事空间；把个人生活数据变成可查询、可回归、可复盘的时间序列档案。

## 3. 项目目标

| 目标 | 衡量标准 |
|---|---|
| 双站上线 | `mobocapital.com` / `mobohome.com` 双主域 + `kb`/`n8n`/`lab`/`admin` 子域可用；受保护入口未认证 401 |
| 投研底座可用 | 宏观论点、策略手册、交易复盘、NAV 高水位与回撤熔断可写入；平仓自动触发净值核算 |
| 知识库可用 | 思源可创建/编辑/搜索；n8n 采集能自动入库并推送高分文章到思源母本 |
| 内容闭环可用 | "1+3"四端合成产出严格 JSON，境内版本自动脱敏 + 免责声明，发布必经人工终审 |
| 档案可计算 | 时间线、阅读、运动、复盘、资产五类数据可写入；周度看板可展示 Z-Score 与 Lead-Lag |
| 数据可恢复 | Restic 每日备份；staging 恢复对账一致；RTO 有实测记录 |
| 成本可控 | 首年基础设施支出 ≤2,400 元并保留 ≥500 元机动；LLM 单独限额并按月对账 |
| 安全达标 | 无公网数据库；全部后台强认证；密钥不入 Git；公域数据包装载前物理脱敏且审计 0 违规 |

## 4. 范围摘要

In/Out、MVP/P1/P2 分层与系统边界图以 [`范围与边界.md`](范围与边界.md) 为唯一清单。本章程不复述包含/不包含长表。架构决策见 ADR-0007～0009。

## 5. 成功标准

1. 16 步部署全部完成，验收清单全绿。
2. 双站连续运行 30 天无 P0 故障；无 OOM、无数据丢失。
3. 备份可恢复，RPO ≤24h；数据库/配置 RTO ≤2h。
4. 首年成本 ≤2,400 元，且至少保留 500 元机动。
5. 运维文档、ADR、密钥清单齐全，后续可独立维护。

## 6. 关键约束

- **硬件**：2C4G，必须 4GB Swap；容器内存硬限流合计 1.64GB；不能跑 Elasticsearch、双 PostgreSQL 实例、重型 OCR。
- **预算**：2,400 元/年红线（基础设施）；LLM/Embedding 单设月度限额；优先 3 年连购/活动价。
- **合规**：大陆服务器 + 域名需 ICP；网站名称规避"基金/投资/理财/量化/金融"等敏感词；内容不得构成投资建议、不得承诺收益、不得募资。
- **时间**：业余推进，预计 3–4 周；ICP 审核 5–10 个工作日可并行部署。
- **单用户**：默认只有莫伯一人使用；不做多租户。
- **内存红线**：任何新常驻进程都必须先证明能塞进 1.55GB 常驻预算（红线一）。

## 7. 假设

- 已有一个阿里云账号，可完成实名/备案。
- 已有或愿意注册 `mobocapital.com` 与 `mobohome.com` 两个主域（或可注册的主域 + 子域）。
- 有可用的 LLM/Embedding API（OpenAI-compatible、Qwen、DeepSeek 等）。
- 本地有 Docker Desktop 或可用的 Linux 开发环境。
- 网站 B 的数据以个人隐私为主，默认全私有；网站 A 的 INTERNAL 数据默认不对外。

## 9. 治理方式

- **决策**：架构级变更写 ADR；数据库变更走 migrations；密钥变更更新清单。
- **节奏**：按 Phase 0–6 推进；每个 Phase 结束做一次 Demo/验收。
- **记录**：`docs/00-总册/文档修订记录.md`、`docs/01-项目治理/风险登记册.md`。
- **质量门**：SQL Smoke Test、Compose config、CLI 单测、恢复演练、验收清单。
