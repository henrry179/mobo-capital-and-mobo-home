## 1. 公共约定

| 约定 | 说明 |
|---|---|
| 可见性 | `visibility ∈ {PUBLIC, LP_PROSPECT, INTERNAL}`，默认 `PUBLIC`；公域导出剔除 `INTERNAL` |
| 主键 | `id UUID PRIMARY KEY DEFAULT gen_random_uuid()` |
| 业务编号 | 人类可读唯一码：`thesis_code` / `strategy_code` / `trade_code` / `doc_slug` / `slug` |
| 时间 | `created_at` / `updated_at` 为 `TIMESTAMPTZ`（库默认 `NOW()` + 触发器）；业务日期用 `DATE` |
| 向量 | `embedding vector(1536)` + HNSW cosine；维度变更必须走迁移 |
| 金额与比率 | `NUMERIC`；NAV 4 位小数、R 倍数 2 位、百分比 2 位 |
| 合规 | 面向境内平台的内容在 `capital_publications` 中保留四端版本；境内版本必须已脱敏 |

## 5. `portfolio_nav_ledger`：组合净值台账

| 列 | 类型 | 空 | 约束/默认 | 说明 |
|---|---|---:|---|---|
| `id` | `UUID` | 否 | PK | — |
| `valuation_date` | `DATE` | 否 | 唯一 | 估值日 |
| `trigger_trade_code` | `VARCHAR(40)` | 是 | — | 触发平仓的交易编号 |
| `gross_nav` | `NUMERIC(10,4)` | 否 | `1.0000` | 毛净值 |
| `high_water_mark` | `NUMERIC(10,4)` | 否 | `1.0000` | **高水位线** |
| `accrued_perf_fee_nav` | `NUMERIC(10,4)` | 是 | `0` | 业绩报酬计提 |
| `net_nav` | `NUMERIC(10,4)` | 否 | `1.0000` | 扣费后净值 |
| `current_drawdown_pct` | `NUMERIC(6,2)` | 否 | `0` | 当前回撤 %（负值） |
| `cumulative_r_multiple` | `NUMERIC(8,2)` | 否 | `0` | 累计 R |
| `risk_regime_status` | `VARCHAR(24)` | 否 | `NORMAL`；`NORMAL/YELLOW_ALERT/RED_CIRCUIT_BREAKER` | 风控状态 |
| `risk_action_note` | `TEXT` | 是 | — | 风控动作说明 |
| `created_at` | `TIMESTAMPTZ` | 是 | `NOW()` | — |

**核算规则**（触发器 `trg_auto_calc_nav_on_trade`）：

- `gross_nav = 1 + Σ(portfolio_impact_bps) / 10000`；
- `high_water_mark = max(prev_hwm, gross_nav)`；
- 业绩报酬：`(gross_nav - 1) × 20%`（仅盈利时计提）；
- 回撤 = `(gross_nav - hwm) / hwm × 100`；
- 回撤 ≤ -5% → `YELLOW_ALERT`（单笔风险下调至 0.75% NAV）；≤ -8% → `RED_CIRCUIT_BREAKER`（总敞口压降至 25% 以内、禁止新开买方期权）。

> 业绩报酬比例与阈值集中在触发器函数内，调整需走 migration。

## 13. 数据质量检查

```sql
-- NAV 与最近一次平仓是否一致
SELECT l.valuation_date, l.gross_nav, l.current_drawdown_pct, l.risk_regime_status
FROM capital.portfolio_nav_ledger l
ORDER BY l.valuation_date DESC LIMIT 5;

-- 未平仓但已记 R 的异常
SELECT trade_code, trade_status, realized_r_multiple
FROM capital.trade_reviews
WHERE trade_status = 'OPEN' AND realized_r_multiple IS NOT NULL;

-- 公域导出前的可见性分布
SELECT visibility, count(*) FROM capital.trade_reviews GROUP BY 1 ORDER BY 1;

-- 发布状态机是否卡在 PENDING_REVIEW
SELECT slug, title, created_at FROM capital.capital_publications
WHERE publish_status = 'PENDING_REVIEW' ORDER BY created_at;
```
