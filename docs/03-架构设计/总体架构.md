# 总体架构

## 1. 目标与原则

在 2C4G 单机上，以最小运行时成本提供两个逻辑独立的网站：

1. **安全边界优先**：公开与私有分离，所有后台强认证。
2. **数据可恢复**：数据库逻辑备份 + 文件卷 + 配置；恢复可验证。
3. **内存可控**：六个容器，硬上限，构建外置，重计算外置。
4. **冷热分层**：原片进 OSS 低频/归档，缩略图留标准层。
5. **可演进**：单机可平滑拆分为多机；数据库可按库迁移。

## 3. 逻辑组件

### 3.1 边缘层

- **Caddy 2.9**：TLS 自动签发/续期、HTTP/2/3、BasicAuth、安全头、反代。
- 五个站点块：`www`、`kb`、`n8n`、`archive`、`admin`。
- 不承担业务逻辑；不做数据库连接。

### 3.2 应用层

| 组件 | 职责 | 状态 |
|---|---|---|
| 思源笔记 | 知识库、双链、编辑、搜索 | 有状态（卷） |
| n8n | 采集、LLM、思源推送、草稿合成 | 有状态（卷 + PG） |
| Streamlit | 个人档案分析看板 | 无状态（读 PG/OSS） |
| 静态操作台 | 任务/入口/状态展示 | 无状态（静态） |
| 公开静态站 | 公开专栏 | 无状态（静态） |

### 3.3 数据层

- **PostgreSQL 16 + pgvector**：双库、三 Schema、触发器、视图、HNSW。
- **OSS 公开 Bucket**：文章配图、公开缩略图。
- **OSS 私有 Bucket**：档案原片、缩略图、Restic 备份。
- **本地卷**：思源工作区、n8n 数据、Caddy 证书、静态站/操作台。

### 3.4 运维层

- **restic-backup**：每日 dump + 卷 + 配置，加密上传 OSS。
- **主机脚本**：Swap、Docker、ufw、fail2ban、日志轮转、监控。
- **外部监控**：uptime、证书到期、磁盘/容器告警。

## 5. 运行时拓扑

```text
Host (2C4G, Ubuntu)
├─ edge_net (bridge)
│  └─ caddy :80/:443
└─ internal_net (internal)
   ├─ postgres :5432
   ├─ mobobrain-pkm :6806
   ├─ mobobrain-n8n :5678
   ├─ archive-dashboard :8501
   └─ restic-backup (no listen)
```

- 只有 Caddy 加入 `edge_net`。
- `internal_net` 设置 `internal: true`，容器不能直接出公网；n8n/CLI 需要访问 LLM/OSS 时，是否允许出网需在 Compose 中确认（`internal` 网络会阻止外部访问）。**实现注意**：若 n8n 需要访问外部 LLM/Jina，需要给它额外加入一个可出网的 bridge 网络，或用 Caddy/代理；本基线在 `docker-compose.yml` 中为 n8n 配置 `egress_net`，并在文档中说明。
- Postgres 只绑定 `127.0.0.1:5432` 供宿主机 CLI 使用。

> **重要**：`internal: true` 会阻断容器出公网。n8n 需要访问 LLM/Embedding/Jina，因此本项目的 Compose 采用 `internal_net`（内部服务）+ `egress_net`（仅 n8n/backup 需要时）双网络，具体见 `deploy` 配置与 `部署架构.md`。

## 6. 故障模式

| 故障 | 影响 | 处理 |
|---|---|---|
| Caddy 挂 | 全部入口不可用 | `docker compose restart caddy`；检查证书/端口 |
| Postgres 挂 | 双站数据不可用 | 重启；检查 OOM/磁盘；必要时恢复 |
| 思源挂 | 知识库不可用；n8n 推送失败 | 重启；n8n 标记待重推 |
| n8n 挂 | 自动化停止；双站仍可读 | 重启；补跑 |
| Streamlit 挂 | 看板不可用 | 重启；不影响数据 |
| OSS 不可用 | 上传/下载/备份失败 | 重试；检查 AK/网络/余额 |
| 主机磁盘满 | 全部异常 | 清日志/镜像/dump；扩容 |

## 7. 演进路径

- **拆分网站 B**：把 Streamlit + `db_archive` 迁到独立 2C4G；OSS 不变。
- **拆分数据库**：把 `db_archive` 迁到独立 PostgreSQL；连接串切换。
- **公开站 CDN**：静态站放 OSS + CDN，Caddy 只做后台入口。
- **多用户**：引入 Authelia/TOTP、RLS、审计；当前不做。
