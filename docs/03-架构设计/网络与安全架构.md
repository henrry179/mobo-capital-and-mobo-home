## 1. 信任边界

```text
[公网]
  │ 80/443
  ▼
[Caddy] ── 终止 TLS、BasicAuth、路由
  │
  ├─ edge_net（仅 Caddy）
  │
  └─ internal_net（internal: true）
        ├─ postgres
        ├─ mobobrain-pkm
        ├─ mobobrain-n8n
        ├─ archive-dashboard
        └─ restic-backup

[egress_net]（仅需要访问公网/OSS/LLM 的容器）
        ├─ mobobrain-n8n
        ├─ archive-dashboard
        └─ restic-backup
```

**规则**

- 只有 Caddy 暴露 80/443。
- Postgres 不暴露公网；宿主机 CLI 经 `127.0.0.1:5432`。
- n8n/看板/备份需要访问 OSS/LLM 时加入 `egress_net`，但不发布端口。
- 思源不加入 `egress_net`；它只被 n8n/Caddy 访问。
- `internal_net` 设置 `internal: true`，阻止容器直接出公网。

## 4. 认证与授权

> 决策摘要见 [ADR-0006](../01-项目治理/决策记录/ADR-0006-安全与鉴权基线.md)（含「不默认 Tailscale/Authelia」）。

### 4.1 网关

- Caddy `basic_auth`，密码哈希由 `caddy hash-password` 生成，Bcrypt cost ≥14。
- 所有受保护站点强制 HTTPS；HTTP 自动跳转。
- BasicAuth 失败日志进入 fail2ban 监控。

### 4.2 应用

- 思源：访问码作为第二层。
- n8n：自身用户/密码；关闭开放注册。
- Streamlit：依赖 Caddy BasicAuth；数据库用只读账号。
- 操作台：静态页，不存密钥。

### 4.3 数据库

| 账号 | 权限 | 用途 |
|---|---|---|
| `postgres` | 超级用户 | 初始化/恢复；不用于应用 |
| `user_mobobrain` | `db_mobobrain` 属主 | n8n 业务/CLI |
| `user_n8n` | `db_mobobrain.n8n` Schema | n8n 自身表 |
| `user_archive` | `db_archive` 属主 | CLI/写入 |
| `user_dashboard_ro` | `archive` SELECT | 看板 |
| `user_backup` | `pg_read_all_data` | 备份 |

## 5. 安全响应头

Caddy 统一添加（实现以 Caddyfile 为准）：

- `Strict-Transport-Security`
- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: DENY`
- `Referrer-Policy`
- `Permissions-Policy`
- 受保护站点：`X-Robots-Tag: noindex, nofollow, noarchive`
- 移除 `Server` 头

公开站 CSP（MVP）：

```text
default-src 'self';
img-src 'self' https://*.aliyuncs.com data:;
style-src 'self' 'unsafe-inline';
script-src 'self' 'unsafe-inline';
object-src 'none';
base-uri 'self';
frame-ancestors 'none'
```

> 后续可移除 `'unsafe-inline'`，改用 nonce/hash。

## 6. 主机安全

- SSH：仅密钥；禁止密码登录 root。
- 安全组 / ufw：22 限制来源；80/443 开放；其他关闭。
- fail2ban：SSH + Caddy 401。
- unattended-upgrades；Docker 日志轮转；不挂 Docker socket。
- 时间同步：systemd-timesyncd / chrony。

## 7. OSS 安全

| Bucket | ACL | 访问 | 防护 |
|---|---|---|---|
| 公开图床 | 公共读 | 文章配图 | 禁止空 Referer；关闭 List |
| 私有档案/备份 | 私有 | 档案/备份 | 签名 URL；SSE（可选） |

- RAM 子账号最小权限；AK/SK 只存 `.env` 与密码管理器。
- Restic 仓库禁止转 Archive（IA 可以），避免 `prune` 403。

## 8. 威胁模型（简版）

| 威胁 | 路径 | 控制 |
|---|---|---|
| 匿名读知识库 | `kb` 直连 | BasicAuth + 思源访问码 |
| 暴力破解后台 | `lab`/`kb`/`n8n`/`admin` | 强密码 + fail2ban + 监控 |
| 数据库暴露 | 5432 | 仅 127.0.0.1 + 安全组 |
| OSS 盗刷 | 公开图床 | 防盗链 + 余额熔断 + 流量告警 |
| 密钥泄露 | Git/日志 | `.gitignore`、`chmod 600`、日志脱敏 |
| 容器逃逸 | 恶意镜像 | 固定镜像、最小权限、不挂 socket |
| 备份被删 | OSS/AK 泄露 | 私有 Bucket、独立 AK、版本控制（可选） |
| 数据丢失 | 误删/磁盘 | 软删除、Restic、演练 |

## 9. 安全验收

- `curl -I` 各受保护入口均 401（未认证）。
- `ss -lntp` 无 `0.0.0.0:5432`。
- `ufw status` 仅 22/80/443。
- `sshd -T` 密码登录关闭。
- `.env` 未被 Git 跟踪。
- OSS 私有 Bucket 匿名 403；公开 Bucket 无 List。
- 安全头齐全；TLS 评级 A（可选 SSL Labs）。
