## 3. 容器编排

  服务   镜像/构建   网络   端口   卷  
 --- --- --- --- --- 
  `caddy`   `caddy:2.9-alpine`   `edge_net` + `internal_net`   80/443/443udp   Caddyfile、caddy_data、site、console  
  `postgres`   `pgvector/pgvector:pg16`   `internal_net`   `127.0.0.1:5432`   pg_data、initdb  
  `mobobrain-pkm`   `b3log/siyuan`   `internal_net`   无   mobobrain_data  
  `mobobrain-n8n`   `n8nio/n8n`   `internal_net` + `egress_net`   无   n8n_data  
  `archive-dashboard`   build `services/archive-dashboard`   `internal_net` + `egress_net`   无   无  
  `restic-backup`   build `deploy/backup`   `internal_net` + `egress_net`   无   dump/staging、mobobrain_data、n8n_data、config  

### 3.1 网络说明

- `edge_net`：普通 bridge，仅 Caddy；提供公网入口和 ACME 出站。
- `internal_net`：`internal: true`，内部服务互通，禁止直接出公网。
- `egress_net`：普通 bridge，成员 n8n/看板/备份/postgres；允许访问 LLM、Jina、OSS 内网 Endpoint。
   postgres 加入是为了让宿主机 CLI 能经 `127.0.0.1:5432` 直连（internal 网络不做端口 DNAT）。
- `postgres` 只在 `internal_net`；宿主机 CLI 通过 `127.0.0.1:5432`。
- 思源只在 `internal_net`，由 Caddy 反代。

### 3.2 内存分配

  服务   mem_limit   说明  
 --- ---: --- 
  caddy   128m   轻量  
  postgres   1024m   shared_buffers 256MB  
  siyuan   512m   工作区/索引  
  n8n   640m   V8 堆 450MB  
  dashboard   512m   Streamlit/Pandas  
  restic   256m   备份  
  **合计**   **3072m**   留 1GB 给 OS/缓存/峰值  

## 4. 构建与发布

### 4.1 本地构建（推荐）

2C4G 服务器上构建 Streamlit 镜像可能 OOM，建议本地/CI 构建后推送镜像仓库，或在服务器低峰构建：

```bash
docker compose build archive-dashboard
docker compose up -d
```

如无镜像仓库，可在本地构建后 `docker save` / `docker load`，或接受服务器构建并确保 Swap 生效。

### 4.2 发布流程

```bash
# 0. 备份当前状态
cd /opt/mobo-stack
docker compose exec -T postgres pg_dump -U "$POSTGRES_SUPER_USER" -Fc db_archive > /tmp/predeploy_archive.dump

# 1. 同步代码（不要覆盖 .env/volumes）
rsync -av --exclude='.env' --exclude='deploy/volumes' ./ user@host:/opt/mobo-stack/

# 2. 校验
docker compose config

# 3. 拉取/构建
docker compose pull
docker compose build

# 4. 滚动重启（按依赖）
docker compose up -d postgres
docker compose up -d mobobrain-pkm mobobrain-n8n archive-dashboard
docker compose up -d caddy restic-backup

# 5. 验收
deploy/scripts/smoke-test.sh
```

### 4.3 回滚

- 镜像回滚：改回上一个 tag/digest，`docker compose up -d`。
- 数据库回滚：使用发布前 dump 恢复；禁止用旧代码配新 Schema。
- 配置回滚：保留上一版 Caddyfile/Compose；`docker compose up -d`。
- 记录：`docs/00-总册/文档修订记录.md`。

## 5. 本地开发

### 5.1 最小启动

```bash
cp .env.example .env
# 填 DB 密码；OSS/LLM 可先留空
docker compose up -d postgres
docker compose up -d archive-dashboard
```

看板无 DB 时自动切沙盒；有 DB 时读真实数据。

### 5.2 完整本地

- 使用 `localhost`/`*.local` 域名；Caddy 本地证书可用 `tls internal`（开发 Caddyfile）。
- OSS 可用 MinIO 模拟 S3；注意 path-style。
- n8n 可用本地 webhook；LLM 可用 mock 服务。

### 5.3 本地目录

```text
./deploy/volumes/          # 运行时数据，Git 忽略
./services/                # 代码
./.env                     # 本地密钥，Git 忽略
```

## 6. 资源与限制

- 不在服务器上跑 `npm install`/大规模 Python 编译；使用预构建镜像。
- 不在服务器上跑 OCR/视频转码；外置到本地/API。
- Postgres `shared_buffers=256MB`、`max_connections=40`、`work_mem=8MB`。
- n8n `NODE_OPTIONS=--max-old-space-size=450`；`SplitInBatches(1)`。
- Streamlit 限制查询行数；缓存；`MALLOC_TRIM_THRESHOLD_=65536`。
- Docker 日志 `max-size=10m`、`max-file=3`。

## 6. 莫伯系统控制台（admin 域）

静态操作台，是"第六个入口"，承担统一观测与操作面：

| 项 | 说明 |
|---|---|
| 代码位置 | `services/console/`（index.html + assets/console.css + assets/console.js） |
| 挂载 | `./services/console:/srv/console:ro`（Caddy 以 `root * /srv/console` 分发） |
| 数据面 | `/api/capital/*`、`/api/home/*` 由 Caddy **同源静态转发**到两站 data 目录（无代理计算 → 0 额外内存） |
| 运行时状态 | `/data/status.json`（由 `tools/wsl/collect-status.sh` 生成）、`/data/gate.json`（由质量门生成） |
| 鉴权 | BasicAuth（与 `/internal/*` 同级保护），响应 `no-store` + `noindex` |
| 原则 | 页面**不直连数据库**、不含任何密钥，只消费已脱敏 JSON |

详细说明与维护约定见 `services/console/README.md`；数据契约由 `services/console/tests/contract-check.mjs` 静态校验（质量门 Q15）。
