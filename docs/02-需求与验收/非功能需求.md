# 非功能需求（NFR）

## 1. 可用性

| ID | 要求 | 目标 | 验证 |
|---|---|---|---|
| NFR-A-01 | 双站可用性 | 月度 ≥99%（单机 + 家用场景） | uptime 记录 |
| NFR-A-02 | 计划维护窗口 | 凌晨 02:00–05:00 | 变更记录 |
| NFR-A-03 | 单容器故障不影响其他容器 | 除 Postgres 外 | 停容器演练 |
| NFR-A-04 | 数据库故障可恢复 | RPO 24h / RTO 2h | 恢复演练 |

## 2. 性能

| ID | 要求 | 目标 | 验证 |
|---|---|---|---|
| NFR-P-01 | 公开页首字节 | <1s（国内） | curl/浏览器 |
| NFR-P-02 | 看板首屏 | <5s（缓存后 <2s） | 浏览器 |
| NFR-P-03 | 单条时间线查询 | <200ms | EXPLAIN |
| NFR-P-04 | 向量 Top-10 | <500ms（10 万条内） | EXPLAIN ANALYZE |
| NFR-P-05 | CLI 上传 10MB 照片 | <30s（含缩略图） | 计时 |
| NFR-P-06 | n8n 单批 20 条 | 不 OOM；串行 | 日志/内存 |

## 3. 容量

| ID | 要求 | 目标 |
|---|---|---|
| NFR-C-01 | 网站 A 存储 | ≤50GB（1–2 年） |
| NFR-C-02 | 网站 B 存储 | 100–500GB（OSS 分层） |
| NFR-C-03 | PostgreSQL | ≤1GB 内存；连接 ≤40 |
| NFR-C-04 | 容器总内存 | 常驻 ≤2GB；峰值 <3.5GB |
| NFR-C-05 | 日志 | 单容器 ≤30MB 滚动 |

## 4. 安全

| ID | 要求 | 目标 |
|---|---|---|
| NFR-S-01 | 传输加密 | 全站 HTTPS；HSTS |
| NFR-S-02 | 后台认证 | BasicAuth；20+ 位密码；Bcrypt 14 |
| NFR-S-03 | 数据库暴露 | 不对公网；仅 127.0.0.1 |
| NFR-S-04 | 密钥 | 不入 Git；`.env` 600；离线副本 |
| NFR-S-05 | OSS | 私有 Bucket 阻止公共；公开 Bucket 防盗链 |
| NFR-S-06 | 主机 | SSH 密钥；ufw；fail2ban；安全更新 |
| NFR-S-07 | 隐私 | 网站 B noindex；数据分类；最小权限 |

## 5. 可靠性与备份

| ID | 要求 | 目标 |
|---|---|---|
| NFR-R-01 | 备份频率 | 每日 03:00 |
| NFR-R-02 | RPO | ≤24h |
| NFR-R-03 | RTO | DB/配置 ≤2h；文件 4–24h |
| NFR-R-04 | 备份校验 | 每周 `restic check`；每月 5% read-data |
| NFR-R-05 | 恢复演练 | 每季度一次，记录 RTO |
| NFR-R-06 | 密钥恢复 | 密码管理器可独立恢复 |

## 6. 可维护性

| ID | 要求 | 目标 |
|---|---|---|
| NFR-M-01 | 文档 | 架构/部署/运维/排障齐全 |
| NFR-M-02 | 迁移 | 所有 DDL 变更走 `migrations/` |
| NFR-M-03 | 配置 | `.env.example` 完整；无硬编码密钥 |
| NFR-M-04 | 版本 | 镜像固定 tag/digest；变更记录 |
| NFR-M-05 | 测试 | Smoke Test 一键执行 |
| NFR-M-06 | 回滚 | 镜像/数据库/配置可回滚 |

## 7. 合规与成本

| ID | 要求 | 目标 |
|---|---|---|
| NFR-L-01 | ICP | 个人备案；名称规避敏感词 |
| NFR-L-02 | 隐私 | 数据分类、访问控制、可导出/删除 |
| NFR-L-03 | 许可证 | 思源 AGPL、n8n Sustainable Use、其他开源合规 |
| NFR-L-04 | 成本 | 首年 ≤2,400 元；保留 ≥500 机动 |
| NFR-L-05 | 告警 | 预算 50 元/月、流量 5 分钟 >500MB、余额 30 元 |

## 8. 兼容性

- 浏览器：Chrome/Edge/Safari 最近两个大版本。
- 移动端：响应式只读 + CLI/PWA 录入（P2）。
- 服务器：Ubuntu 22.04/24.04 LTS；Docker Compose v2。
- 本地：Windows Docker Desktop / macOS / Linux。
- 时区：`Asia/Shanghai`；数据库 `TIMESTAMPTZ`。
