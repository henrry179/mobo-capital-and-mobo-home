**版本：2026-10-07**  
**用途：**统一记录用户提出/确认的信息、AI整理与架构建议、官方验证信息，并形成可持续更新的项目基线。

> **信息来源标识**
> - **【用户】**：用户本人在本轮及连续讨论中明确提出、确认或要求的事实、目标、偏好和约束。

> - **【官方验证】**：根据官方产品/文档资料核对的当前能力或规则；购买、部署前仍应以当时账户和官方页面为准。

# 1. 项目总定义

## 1.1 【用户】项目定位

用户希望把全球宏观、财经、金融市场、股票、期权、交易研究等内容发展为副业方向，并逐步打造：

> **One Person Company（OPC / 一人公司）式的全球财经金融研究与媒体内容业务。**

长期目标是形成：

> **个人 + AI 智能体团队 + 知识资产 + 内容分发网络 = 全球财经金融 OPC**

核心不是单纯让 AI 写文章，而是通过 AI Agent 建立可持续运行的个人 AI 团队，承担研究、生产、组织、分发和日常运营中的可重复工作。

## 1.2 【用户】主业与副业关系

用户当前主业定位为零售行业商业数据分析、经营分析、商业分析相关岗位；主业提供现金流和现实职业基础。

副业重点逐步转向：
- 全球宏观
- 全球金融市场
- 股票
- 期权
- 交易研究
- AI/科技
- 财经金融内容生产
- 中文/英文内容分发

## 1.3 【AI整理】统一业务模型

```text
Founder / User
      ↓
AI Research Team
      ↓
AI Production Team
      ↓
Knowledge Assets
      ↓
Content Distribution
      ↓
Global Audience
      ↓
One Person Company
```

# 5. 【官方验证】Grok Bot 的能力边界

根据项目底稿中的官方资料核验记录，Grok Bot 具备以下产品构件：

### 5.1 持久化 AI teammate

每个 Bot 可以拥有：
- 名称
- 工作职责
- 持续上下文
- 工具能力
- 多步骤任务执行环境

### 5.2 Skills

Skill 用于定义：
- 如何完成任务
- 工作步骤
- 判断规则
- 输出要求
- 安全边界

### 5.3 Routines

Routine 用于定义：
- 什么时候执行
- 按什么周期执行
- 在什么支持的事件条件下执行

因此可以形成：

```text
Bot
 ↓
Skill = 怎么做
 ↓
Routine = 什么时候做
```

### 5.4 Connectors

项目底稿记录的官方能力包括 GitHub 等连接器，以及自定义 MCP 路径。

对于本项目，核心逻辑是：

```text
MoboBrain / GitHub
        ↓
GitHub Connector
        ↓
Grok Bot
```

### 5.5 Computer / Browser / Cloud execution

Grok Bot 的云端执行能力适合：
- Web research
- 浏览网页
- 文件处理
- 多步骤任务
- 外部工具协作
- 周期性情报任务

# 13. 【AI建议】全球金融内容的语言本地化

中文 Master Research 不应简单机械翻译成英文。

正确流程：

```text
Chinese Master Research
        ↓
Fact / Data / Thesis
        ↓
Global Context
        ↓
English Financial Edition
        ↓
Regional Localization
```

例如同一 Fed 研究：

| 市场 | 本地化重点 |
|---|---|
| US | Fed Funds / Treasury / Nasdaq / S&P 500 |
| China | RMB / A-shares / H-shares / PBOC |
| Japan | BOJ / JGB / JPY / Carry Trade |
| Korea | BOK / KRW / KOSPI / Semiconductors |
| India | RBI / INR / Nifty / FII |
| Singapore | SGD / REITs / Banks / ASEAN Capital |
| Europe | ECB / EUR / Bund / STOXX |
| Middle East | Oil / USD / GCC Liquidity / Gold |

这属于：

> **Localized Financial Intelligence**

而不只是 Translation。

# 14. 【AI建议】全球金融内容合规边界

所有内容建议区分：

```text
Fact
 ↓
Data
 ↓
Research Interpretation
 ↓
Scenario
 ↓
Assumption
 ↓
View
 ↓
Trading Framework
```

避免把：
- AI 推断
- 模型判断
- 情景假设

直接表述成：
- 已发生事实
- 确定性预测
- 个性化投资建议

## 风险分级

### GREEN
- 宏观研究
- 历史数据
- 公司/行业研究
- 财报分析
- 估值方法
- 市场结构
- 风险管理教育
- 金融知识教育

### AMBER
可能被理解为投资观点或推荐的表达，例如：
- “We expect NVDA to outperform.”
- “USDJPY may move to 155.”
- “Preferred trade is long gold.”

需要进一步进行地区与平台规则审查。

### RED
原则上进入人工审核/拦截：
- “Buy now”
- “Sell now”
- “Follow my trades”
- “Guaranteed returns”
- “Copy my trades”
- “Guaranteed profit”
- Paid signals
- Managed accounts
- Broker referral
- Copy trading

> Disclaimer 本身不是全球统一的免责机制；内容实质、语境、受众、商业模式和目标司法辖区共同决定监管风险。
