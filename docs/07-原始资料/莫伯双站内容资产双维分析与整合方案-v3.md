### 0.2 五条判断

1. **空间高度集中**：两个顶层目录占 97.8%，其中 `ITPM-PlayBooks/PodcastPlayBooks/Videos` 一个目录就 15.22 GB。整理必须按“目录分支”拆，不能全仓平均用力。
2. **体积与价值倒挂**：视频 61 个文件占 43.3% 体积；Markdown 19,225 个文件占 42.9% 数量，却只占 0.52% 体积。站点同步的核心是 Markdown / Word 精选 / 封面缩略图，不是大媒体。
3. **重复量已精确到 2.45 GB**：PDF 课件存在“根 `ITPM原稿内容` ≡ `Autopilot/01_原始文档/ITPM原稿内容` ≡ `WorkFiles/data/input`”三副本；封面存在 `06-IMAGES` 与 `mobobrain-assets/covers` 双份；Hermes 备份里 `skills.tar.gz` 重复 18–25 份。
4. **11.05 GB 不是内容资产**：25 份 Hermes 快照 6.60 GB + 嵌套 `.git` 4.43 GB。它们不应进内容金库，也不应上 ECS；其中 5.2 GB 旧快照可按保留策略隔离。
5. **“一份原件、两个视图”**：不要按 A/B 站复制两套媒体。金库只存一份原件，用 `SITE-ROUTING.csv` 的 `site` 字段派生 A/B 两个导出清单；否则 OSS 双倍计费、版本必然分叉。

### 1.2 两个维度

| 维度 | 口径 | 回答的问题 |
|---|---|---|
| **维度 A · 空间** | 按目录累计字节数，一级 / 二级 / 三级 / 四级 | 空间被谁占了？先拆哪个目录？ |
| **维度 B · 类型** | 按扩展名归并为 14 类：Word / PDF / 视频 / 图片 / 音频 / Markdown / 文本 / 代码 / 演示表格 / 数据库 / 版本库 / 压缩包 / 字体 / 其他 | 哪类文件最重？哪类值得上站？ |
| **交叉** | 目录 × 类型矩阵 | 某个大目录“重”在哪类文件？能不能直接同步？ |

### 1.3 去重与分流口径

- **精确重复**：只对“存在同尺寸同伴”的 22,871 个候选文件做完整 SHA-256；按哈希分组，同组保留 1 份，其余计为冗余。无失败文件。
- **去向估算**：按目录规则做“A 站 / B 站 / People 存档 / 冷存档 / 版本库与备份 / 工程与治理 / 运维内部 / 临时”粗分流。它是**目录级估算**，不是逐文件发布判定；A/B 候选仍须 HITL、脱敏与版权复核。
- **内容计数**：Word / PDF / 图片等“有效内容”计数已排除 `~$*` 临时文件与 `._*` macOS 资源叉；总文件数仍包含它们（75 个）。
- **单位**：GB = 1024 MB = 1024³ B；与 Windows 资源管理器口径一致。

### 1.4 局限

- 未做 OCR、未用 ffprobe 读视频时长、未逐篇读 Word/PDF 正文；分类依据扩展名与目录语义。
- 去重只覆盖“同尺寸候选”，能抓到字节级副本，抓不到转码 / 重新压缩 / 改名的近似副本。
- `hermes-migration` 内嵌 `.git` 的对象未逐 blob 审计；上线前仍需 `gitleaks`。
- 目录去向规则是“整理地图”，最终发布仍以 `MANIFEST.csv` + HITL 为准。

### 3.7 类型维度的结论

- **站点同步只需要两类东西**：① 文本层（Markdown / 精选 Word / PDF 元数据）；② 封面缩略图。其余大媒体只做“冷存 + 元数据”。

- **视频是最大单一项，也是最不该上站的一项**：15.22 GB 课件视频只做本地冷存，不占 ECS、不进 Git、不直链。

### 6.3 为什么不是“按 A/B 站分两个大文件夹”

Get-ChildItem -LiteralPath $root -Recurse -File -Force |
  ForEach-Object {
    $rel = $_.FullName.Substring($root.Length + 1)
    $parts = $rel -split '\\'
    $top = if ($parts.Count -gt 1) { $parts[0] } else { '(root)' }
    [pscustomobject]@{
      path=$rel; name=$_.Name; ext=$_.Extension.ToLowerInvariant();
      size=$_.Length; mtime=$_.LastWriteTime.ToString('yyyy-MM-dd HH:mm:ss');
      top=$top; depth=$parts.Count
    }
  } | Export-Csv "$env:TEMP\mobo_inventory.csv" -NoTypeInformation -Encoding UTF8

# 2) 聚合
python build_analysis.py "$env:TEMP\mobo_inventory.csv"
# 3) 精确去重（完整 SHA-256，约 1–2 分钟）
python build_duplicates.py "$env:TEMP\mobo_inventory.csv"
python summarize_duplicates.py
# 4) 生成仪表板
python build_dashboard.py
