## 6. 重复、噪声与风险（入库前必处理）

### 6.1 重复副本（至少三处）

| 内容族 | 出现位置 |
|---|---|
| AIGC / 《亿万》 | 根 `AIGC原稿/` ≡ `Autopilot…/01_原始文档/AIGC原稿/` |
| ITPM PDF / 交易真相 / 10 Secrets | 根 `ITPM原稿内容/` ≡ `Autopilot…/01_原始文档/ITPM原稿内容/` ≡ Peoples `07-MKPlayBooks` / TOP100 authors |
| 根 4× docx | 多份亦在 `01_原始文档/`、Peoples `05` |

**原则**：每族定一个 **Canonical（权威源）**，其余标 `DUPLICATE` 或删链，避免 OSS 三倍计费。

### 6.2 敏感与凭据（VAULT）

| 路径 | 风险 |
|---|---|
| `AutopilotTradeBoMo/010-分析报告/18+APP-id-APP-secret.txt` | AppId/Secret 明文 |
| `hermes-migration/.../管道/.env`、`hermes/.../.env`、`env.txt` | API Key 类 |
| `WorkFiles/.../generated_password*.txt` | 生成口令残留 |
| 嵌套 `henrry-push/.git`（~4.5 GB） | 历史对象可能含密钥；**勿整仓推到生产 Git** |

处理：迁密码管理器 → 轮换 → 从工作区删除或改名进 `secrets/`（已在根 `.gitignore`）。

### 6.3 体积红线（对照架构宪章）

- 单机 **2C4G**，ECS 本地只留热数据；**15 GB 视频 + 4 GB 人物剧照**必须走 **OSS 内网 + 冷存**。
- 禁止把 `PodcastPlayBooks/Videos`、`01-影视库` 原图、Hermes 全量备份打进 Docker 卷。
- Git：根 `.gitignore` 已忽略 `*.zip`；内容原料仓应 **整目录 ignore**，仅提交本盘点文档与精选 MD。

### 6.4 版权与合规

- ITPM/POTM/PTM 课件、播客视频、第三方作者全文：**INTERNAL / 个人学习**；公域发布须脱敏 + HITL（见 ADR-0009）。
- 微信/雪球版本继续执行「无具体买卖点位 + 免责声明」。
- 字体（SimHei 等）商用前核授权。
