## 3. 原件保全规则（最重要）

### 3.1 六条“不”

1. **不合并**：不把多篇 MD/Word/PDF 合成一篇。
2. **不转换**：Word 不转 MD/HTML；PDF 不抽文本/不 OCR；Excel 不转 CSV；Markdown 不改写。
3. **不注入**：不在 MD 文首加 YAML；不改标题、日期、链接、标点。
4. **不改名**：保留原文件名与扩展名；目录可以按类型/站点重组，文件名不变。
5. **不删除**：源文件、重复件、历史版本都保留；只做复制。
6. **不覆盖**：目标存在同名文件时，用 `path + sha256` 区分，不覆盖。

### 3.2 复制与校验

```text
源文件（只读）
  → COPY（保留相对路径 / 文件名 / 时间戳）
  → SHA-256（源与副本各算一次）
  → 登记 MANIFEST.csv
  → 抽样/全量比对
  → 源文件保持不动
```

`MANIFEST.csv` 列：

```text
asset_id,legacy_path,vault_path,file_name,ext,media_class,bytes,sha256,site,visibility,package,duplicate_of,notes,copied_at
```

- `media_class` ∈ `md|xlsx|docx|pdf|image|archive|code|font|other`
- `site` ∈ `capital|home|shared|local|none`
- `visibility` ∈ `PUBLIC|LP_PROSPECT|INTERNAL|PRIVATE|LOCAL|VAULT`
- `package` ∈ `sync|local|excluded|cleanup`

### 3.3 People 剧照与课件 PDF/Word：建议

你问“是否只留元数据、原件冷存”——**不建议只留元数据**，因为与你第 1、2 条冲突。建议分三层：

| 层 | 放什么 | 放哪 | 公网 |
|---|---|---|---|
| 展示层 | 片页/封面缩略图、标题、年份、人物、简介 | 站点 JSON + `media/thumbnails` | ✅ 仅缩略图 |
| 原件层 | 剧照原图、课件 PDF/Word 原件 | 服务器 `/private/library/` 或 OSS 私有桶 | ❌ |
| 本地层 | `01-影视库` 全部；`MoBoBrain` 全部 | 本地金库 `70-Archive-Immutable/` | ❌ |

- **People 剧照**：`01-影视库` 按你第 4 条只本地；02–07 的图片/文档同步服务器，但原件进私有区，公开页只用缩略图。
- **课件 PDF/Word**：原件保留并同步私有区；公网不直链；如未来要公开，需版权确认 + HITL。
- **不做 OCR/文本抽取**：因此不生成全文搜索；先用文件名、目录、标题、标签、MANIFEST 做索引。

- `private/` 不进 Caddy root；只允许 SSH/运维访问。

### 5.2 上传顺序

```text
① 冻结清单 + SHA-256
② 复制到本地金库（原件，不改）
③ 生成 MANIFEST / TYPE-VIEW / SITE-ROUTING
④ 上传原件到 private/library 或 OSS（只增不删）
⑤ 生成并上传公开展示层（缩略图 + JSON）
⑥ 原子切换 JSON
⑦ 冒烟 + 回滚点
```

**不转换**意味着没有“转换失败”风险，但仍有复制/哈希/权限/路径风险；因此每步都要校验。

### 5.3 上传命令（示例）

```bash
# 1) 原件：按清单 rsync 到私有区；不用 --delete
rsync -avz --checksum --files-from=00-INDEX/SYNC-FILES.txt \
  /mnt/e/.../MoBo-Content-Vault-v5/ \
  mobo@server:/opt/mobo-stack/private/library/

# 2) 公开展示层：内容寻址，只增不删
rsync -avz --checksum 80-Site-Release/capital/public/ \
  mobo@server:/opt/mobo-stack/sites/mobocapital/

# 3) JSON 原子切换（同上）
mv public-data.json public-data.json.prev
mv public-data.json.new public-data.json
```

> 注意：`rsync --files-from` 只传清单内文件；清单必须显式排除 `01-影视库`、`MoBoBrain`、视频、音频、`.git`、快照。
