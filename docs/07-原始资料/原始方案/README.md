- 目标机：**8 vCPU / 8 GB**，工具链含 Hermes / Grok Bot 等更重组合。  
- 与红线一冲突：当前禁止引入超出六容器硬限流的常驻后端。  
- 若未来扩容，须先写新 ADR，再改 Compose；**不得**直接按该 docx 部署。
