# 证据目录

本地阶段（[ADR-0010](../../01-项目治理/决策记录/ADR-0010-本地优先开发暂不进入公网部署.md)）自检留痕目录，
对应 [`本地阶段自检清单.md`](../本地阶段自检清单.md)。

## 目录约定

```text
证据/
├─ README.md                      # 本说明（入库）
└─ YYYYMMDD-本地自检/             # 每次自检一个文件夹（默认不入库）
   ├─ 00-summary.txt              # 各小节结论汇总
   ├─ L0-编排校验.txt
   ├─ L1-冒烟输出.txt
   ├─ L2-脱敏审计.txt
   ├─ L3-工作流落库.txt
   ├─ L4-备份与演练.txt
   ├─ L5-质量门.txt
   └─ screenshots/                # 关键界面截图（看板、门户、n8n、401 提示）
```

## 留痕要求

1. 每次自检新建一个 `YYYYMMDD-本地自检/` 文件夹，**不要覆盖历史**。
2. 文本输出用 `tee` 直接落盘，例如：

   ```bash
   mkdir -p docs/05-运维与灾备/证据/$(date +%Y%m%d)-本地自检
   EV=docs/05-运维与灾备/证据/$(date +%Y%m%d)-本地自检
   dc exec -T postgres psql -U postgres -d db_archive -f /tmp/smoke.sql | tee $EV/L1-冒烟输出.txt
   ```

3. 关键界面（看板四模块、两个门户、n8n 待审队列、`/internal/*` 的 401 提示）截图存 `screenshots/`。
4. 在自检清单的「证据/备注」列写明文件名，在「异常与待办」登记所有 ❌ 项。
5. 目录内容默认**不入 Git**（体积与隐私考虑）；需要留档时手动 `git add -f` 关键文件。

## 隐私提醒

证据里可能包含本地测试数据、端口信息与界面内容。**禁止**把以下内容放进证据目录：
真实 AK/SK、`.env` 内容、n8n 凭证、私有 OSS 签名链接、生产数据导出。
