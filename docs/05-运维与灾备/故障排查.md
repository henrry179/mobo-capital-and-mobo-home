# 故障排查

> 顺序：**先看现象 → 再看容器 → 再看日志 → 再看网络 → 最后动数据**。不要在未备份时删卷/改库。

## 1. 快速定位表

| 现象 | 最可能原因 | 先做什么 |
|---|---|---|
| 全站打不开 | Caddy 挂了/DNS/安全组/证书 | `docker compose ps caddy`；`curl -I`；看 80/443 |
| `www` 502 | Caddy 找不到静态目录 | 检查 `site/` 挂载与 `root` |
| `kb` 502 | 思源未启动/健康检查失败 | `docker compose logs mobobrain-pkm` |
| `n8n` 502 | n8n 启动慢/数据库连接失败 | 看 n8n 日志与 `n8n` Schema |
| `archive` 502 | 看板崩溃/DB 不可连 | 看 dashboard 日志；DB 连接 |
| 一直弹 401 | BasicAuth 哈希/用户名错误 | 重新生成哈希；检查 `.env` 引号 |
| 证书错误 | 80 被占/DNS 未生效/备案 | `dig`；`curl http://.../.well-known/acme-challenge/` |
| 数据库没表 | 初始化失败/非空卷 | 看 postgres 日志；确认 `pg_data` 为空时首次启动 |
| n8n 凭证报错 | 加密密钥变了 | 恢复原 `N8N_ENCRYPTION_KEY` |
| 看板空白 | DB 无数据/查询失败 | 看板会切沙盒；查 `ARCHIVE_DB_*` |
| 上传失败 | OSS AK/Endpoint/Bucket 错 | `mobo-cli doctor`；看 OSS 错误码 |
| 备份失败 | Restic 密码/网络/Bucket | 手工跑脚本；看日志 |
| 磁盘满 | Docker 日志/旧镜像/备份 staging | `df -h`；`docker system df` |

## 2. 通用诊断

```bash
cd /opt/mobo-stack

# 2) 资源

docker network ls
```

## 3. Caddy / HTTPS

### 3.1 401 循环

- `CADDY_ADMIN_PASSWORD_HASH` 必须是 **Bcrypt**，且 `.env` 中用单引号包裹 `$`。
- 生成：
  ```bash
  docker run --rm caddy:2.9-alpine caddy hash-password --plaintext '你的密码'
  ```
- 验证：
  ```bash
  docker compose exec caddy caddy validate --config /etc/caddy/Caddyfile
  docker compose up -d --force-recreate caddy
  ```

### 3.2 证书申请失败

```bash
docker compose logs caddy | grep -Ei 'acme|certificate|error'
dig +short www.example.com
curl -I http://www.example.com/.well-known/acme-challenge/test
```

- DNS 未生效：等待 TTL。
- 80 被安全组阻断：放行 80。
- 备案未通过：Caddy HTTP-01 可能被拦截；改用 DNS-01 或暂缓。
- 速率限制：Let's Encrypt 失败次数过多，等待或换 staging CA 调试。

### 3.3 502

```bash
docker compose exec caddy wget -qO- http://archive-dashboard:8501/_stcore/health
docker compose logs --tail=100 archive-dashboard
```

- 看板未 healthy：镜像构建失败/内存不足/DB 连接超时。
- n8n 未 healthy：数据库迁移慢，等 60–120 秒；仍失败看 n8n 日志。
- 思源 502：工作区权限/端口；`docker compose logs mobobrain-pkm`。

## 4. PostgreSQL

### 4.1 初始化失败

```bash
docker compose logs postgres | tail -n 200
docker compose exec -T postgres psql -U postgres -d postgres -c '\l'
```

常见：

- `\getenv` 变量为空：`.env` 缺 `*_DB_PASSWORD`。
- `role already exists`：卷不是空的但部分初始化完成；不要直接重跑全部脚本。
- `extension "vector" is not available`：镜像不是 `pgvector/pgvector:pg16`。
- 权限错误：初始化脚本必须以 `postgres` 运行。

### 4.2 连接数耗尽

```sql
SELECT datname, usename, state, count(*)
FROM pg_stat_activity GROUP BY 1,2,3 ORDER BY 4 DESC;
```

- 看板连接未关闭：检查 `db_connect` 的 `finally close`。
- n8n 并发高：降低并发/执行数。
- 长事务：`SELECT pid, now()-xact_start, query FROM pg_stat_activity WHERE xact_start IS NOT NULL;`

### 4.3 慢查询

```sql
SELECT pid, now()-query_start AS dur, query
FROM pg_stat_activity
WHERE state='active' AND now()-query_start > interval '30 seconds';
```

> 不要直接 `pg_terminate_backend` 生产连接，先确认事务是否在写入。

## 5. n8n

```bash
docker compose logs --tail=200 mobobrain-n8n
docker compose exec -T postgres psql -U postgres -d db_mobobrain -c '\dt n8n.*'
```

- `relation "n8n.workflow_entity" does not exist`：n8n 首次迁移未完成/DB 用户无 CREATE；检查 `user_n8n` 权限。
- `The encryption key...`：`N8N_ENCRYPTION_KEY` 与备份时不一致。
- 工作流执行失败：看执行详情；检查 `intel.ingestion_runs.error_message`。
- Webhook 404：Caddy 子域/`WEBHOOK_URL` 不匹配；不要用子路径。
- 内存不足：`NODE_OPTIONS` 450MB；降低并发，清理旧执行。

## 6. 思源

```bash
docker compose logs --tail=200 mobobrain-pkm
ls -la deploy/volumes/mobobrain_data | head
```

- 打不开/403：`SIYUAN_ACCESS_AUTH_CODE` 错；Caddy 401 与思源访问码是两层。
- 附件丢失：检查卷挂载与备份。
- 升级后白屏：清浏览器缓存；核对镜像版本；回滚镜像 tag。
- 权限：容器内用户通常 UID 1000；`chown -R 1000:1000 deploy/volumes/mobobrain_data`。

## 7. 看板

```bash
docker compose logs --tail=200 archive-dashboard
curl -fsS http://127.0.0.1:8501/_stcore/health   # 若端口未映射，用容器内
docker compose exec archive-dashboard curl -fsS http://127.0.0.1:8501/_stcore/health
```

- 页面一直转圈：WebSocket 被反代阻断；Caddy 默认支持，检查中间网络。
- 显示沙盒：DB 连接失败/无数据；看页面警告文本；`mobo-cli doctor`。
- `permission denied for table`：`user_dashboard_ro` 未授权；重跑 `05` 的 GRANT 部分。
- 内存 512MB 不够：限制查询窗口/升级到 1GB。

## 8. OSS / CLI

```bash
cd services/mobo-cli
mobo-cli doctor
mobo-cli upload test.jpg --dry-run
```

常见错误：

| 错误 | 处理 |
|---|---|
| `InvalidAccessKeyId` | AK 错/被禁用 |
| `SignatureDoesNotMatch` | SK 错/系统时间偏差 |
| `NoSuchBucket` | Bucket/Endpoint/地域不匹配 |
| `AccessDenied` | RAM 权限缺 `PutObject`/`GetObject` |
| `RequestTimeTooSkewed` | 同步 NTP：`chronyc makestep` |
| 上传慢 | 用内网 Endpoint；检查带宽 |

## 9. Restic / 备份

```bash
docker compose logs --tail=200 restic-backup
docker compose exec -T restic-backup restic snapshots --latest 3
docker compose exec -T restic-backup restic check
```

- `wrong password`：`.env` 的 `RESTIC_PASSWORD` 与仓库不一致。
- `repository does not exist`：首次未 `init`；脚本会自动 init，检查 OSS 前缀。
- `s3: ... connection refused`：Endpoint/网络/DNS；服务器用内网 Endpoint。
- `Fatal: unable to create lock`：并发备份/上次锁未释放；`restic unlock`（确认无运行任务）。
- 备份成功但恢复失败：做 `restore-drill.sh`，不要只看快照列表。

## 10. 磁盘/内存

```bash
du -sh deploy/volumes/* | sort -h
docker system df
journalctl --disk-usage
```

清理：

```bash
# 只清停止的容器/悬空镜像/构建缓存
docker container prune -f
docker image prune -f
docker builder prune -f

# 日志（确认服务已重启）
truncate -s 0 deploy/volumes/caddy_logs/access.log
```

> 不要清 `pg_data`、`mobobrain_data`、`n8n_data`、`caddy_data`。

## 11. 事故处理顺序

1. **止血**：重启/摘除故障入口/关停异常工作流。
2. **保留现场**：复制日志、`docker inspect`、`pg_stat_activity`。
3. **恢复**：按备份/回滚手册。
4. **复盘**：时间线、根因、改进项、责任人、截止日期。
5. **验证**：Smoke Test + 业务抽查。
