# 本地开发与部署指南（Local-First）

> 依据 [ADR-0010](../01-项目治理/决策记录/ADR-0010-本地优先开发暂不进入公网部署.md)：双主域未注册、ICP 未启动，**当前只做本地开发与部署**，不进入公网上线。
> 本地阶段：云端支出 ≈ 0，LLM 消耗计入 ≤ ¥150/月 额度，真数据不进本地。

## 0. 本地阶段做什么 / 不做什么

| 做 | 不做（挂起） |
|---|---|
| 容器编排与数据库内核验证（01~09 SQL、`smoke.sql`） | 采购 ECS / 开通 OSS / 双桶与 RAM 子账号（T01–T03） |
| 看板、CLI（含投研录入与脱敏导出）本地跑通 | 双域 DNS、ICP 备案、正式证书（T04、T11） |
| 双站门户与静态数据包本地生成与预览 | 微信草稿箱直推、X 发布（只产出 JSON 草稿） |
| n8n 工作流 #1/#2/#3 阶段一（合成 → 待审队列） | 工作流 #3 阶段二（发布） |
| 本地 Restic 备份 + 恢复演练 | 生产 OSS 冷备、异地副本 |
| 公网就绪材料（清单、脚本、密钥占位） | 真实密钥落盘、真实域名解析 |

## 2. 本地环境变量

生产用 `.env`（600）；本地另建 **`.env.local`**，不与生产混用。

```bash
cp .env.example .env.local
```

`.env.local` 建议覆盖（其余保持默认即可）：

```dotenv
# --- 本地覆盖 ---
DOMAIN_CAPITAL=localhost
DOMAIN_HOME=mobohome.localhost
DOMAIN_PKM=kb.localhost
DOMAIN_N8N=n8n.localhost
DOMAIN_ADMIN=admin.localhost
DOMAIN_LAB=lab.localhost

# 账号口令：本地随便起，生产必须替换
PG_SUPER_PASSWORD=LocalDev_Super_2026!
PG_PASS_MOBOBRAIN=LocalDev_MoboBrain_2026!
PG_PASS_ARCHIVE=LocalDev_Archive_2026!
N8N_DB_PASSWORD=LocalDev_N8n_2026!
DASHBOARD_DB_PASSWORD=LocalDev_Dashboard_2026!
BACKUP_DB_PASSWORD=LocalDev_Backup_2026!
SIYUAN_ACCESS_AUTH_CODE=LocalDev_Siyuan_2026!
N8N_ENCRYPTION_KEY=LocalDev_N8N_Encryption_Key_32Chars_Long!!
CADDY_ADMIN_USER=mobo
CADDY_ADMIN_PASSWORD_HASH='$2a$14$REPLACE_WITH_REAL_BCRYPT_HASH'

# 本地无 OSS 时留空（看板与 CLI 会降级）；需要真对象存储时填自己的测试桶

ALIYUN_ACCESS_KEY_SECRET=
MOBOCAPITAL_WEB_DIR=./sites/mobocapital
MOBOHOME_WEB_DIR=./sites/mobohome
```

> **本地 HTTP 与 HTTPS**：仓库提供两份网关配置——
> - `deploy/caddy/Caddyfile`（生产）：自动 HTTPS + ACME，需要公网域名与 80/443 可达；
> - `deploy/caddy/Caddyfile.local`（本地）：**纯 HTTP**，不申请证书，配 `docker-compose.local.yml` 使用。
>
> 本地入口（`*.localhost` 由浏览器按 RFC 6761 自动解析到 127.0.0.1）：
>
> | 入口 | 地址 | 认证 |
> |---|---|---|
> | 莫伯资本 | `http://localhost/` | 公开 |
> | 莫伯之家 | `http://mobohome.localhost/` | 公开 |
> | 生命体征实验室 | `http://lab.localhost/` | BasicAuth |
> | 思源笔记 | `http://kb.localhost/` | BasicAuth |
> | n8n | `http://n8n.localhost/` | BasicAuth |
> | 操作台 | `http://admin.localhost/` | BasicAuth |
> | 内网驾驶舱 | `http://localhost/internal/internal-data.json` | BasicAuth（期望 401） |
>
> 也可绕过网关直连（仅环回地址）：看板 `http://127.0.0.1:8501`、n8n `http://127.0.0.1:5678`、思源 `http://127.0.0.1:6806`、PostgreSQL `127.0.0.1:5432`。

## 3. 启动

```bash
cd <项目根>

# 0) 校验编排（本地覆盖）
docker compose -f docker-compose.yml -f docker-compose.local.yml --env-file .env.local config >/dev/null

# 1) 只起数据库（首次会执行 01~09 初始化脚本）
docker compose -f docker-compose.yml -f docker-compose.local.yml --env-file .env.local up -d postgres
docker compose -f docker-compose.yml -f docker-compose.local.yml --env-file .env.local logs -f postgres | grep -Ei 'ready|error'

# 2) 校验结构
docker compose -f docker-compose.yml -f docker-compose.local.yml --env-file .env.local exec -T postgres \
  psql -U postgres -d db_mobobrain -c '\dt capital.*'

# 3) 跑冒烟（9 组检查）
docker compose -f docker-compose.yml -f docker-compose.local.yml --env-file .env.local \
  cp tests/sql/smoke.sql postgres:/tmp/smoke.sql
docker compose -f docker-compose.yml -f docker-compose.local.yml --env-file .env.local \
  exec -T postgres psql -U postgres -d db_archive -v ON_ERROR_STOP=1 -f /tmp/smoke.sql

# 4) 起全栈
docker compose -f docker-compose.yml -f docker-compose.local.yml --env-file .env.local up -d --build
docker compose -f docker-compose.yml -f docker-compose.local.yml --env-file .env.local ps
docker stats --no-stream      # 观察常驻内存是否接近 1.46GB
```

> **简化别名**（在项目根放一个 `docker-compose.override.yml` 或用 shell 函数），后续命令可省略 `-f` 参数：
> ```bash
> alias dc='docker compose -f docker-compose.yml -f docker-compose.local.yml --env-file .env.local'
> ```

> 初始化脚本**只在空 `pg_data` 卷首次启动执行**。改 SQL 后要重来：
> ```bash
> docker compose -f docker-compose.yml -f docker-compose.local.yml --env-file .env.local down
> docker compose -f docker-compose.yml -f docker-compose.local.yml --env-file .env.local rm -f postgres   # 只删数据卷，慎用
> ```
> 有真实数据时**绝不**执行 `rm -f`。

## 9. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 容器反复重启 | 内存不足 | Docker Desktop 内存调到 ≥4GB；`docker stats` 看谁超限 |
| 证书报错 | 本地无公网域名 | 用 `http://localhost:<port>` 直连应用，或用 `Caddyfile.local` 关闭 auto_https |
| `smoke.sql` 报缺表 | 初始化脚本未执行（卷非空/曾失败） | 看 `docker compose logs postgres`；修复后删卷重来（无真实数据时才可） |
| `pgvector` 扩展不存在 | 镜像不对 | 必须 `pgvector/pgvector:pg16` |
| 看板无数据 | 未灌沙盒或 DB 不可达 | 灌 `seeds/52-week-sandbox.sql`；看板会自动降级为沙盒模式 |
| `export-site` 报脱敏校验失败 | 导出逻辑与字段清单不一致 | 看异常里的 `private_field_violations`，补 `exporters.PRIVATE_FIELDS` |
| 端口被占用 | 本机已有 80/443 | 改 compose 端口映射（如 `8080:80`）或停占用进程 |
