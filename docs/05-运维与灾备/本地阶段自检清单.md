```bash
cd <项目根>
cp .env.example .env.local        # 首次；按指南覆盖本地口令与 localhost 域名
```

## 12. 复检触发条件

出现以下任一情况必须重跑相关小节：

- 变更 `deploy/postgres/initdb/` 任一 SQL → 重跑 **L1**（含重建库）与 **L5-06**
- 变更 `deploy/caddy/Caddyfile*` → 重跑 **L2-15**
- 变更 `services/mobo-cli/mobo_cli/exporters.py` → 重跑 **L2-10/11/12** 与 **L5-05**
- 变更 `docker-compose*.yml` → 重跑 **L0-02/03/07** 与 **L5-07**
- 变更工作流模板 → 重跑 **L3-05/06/07**
- 升级容器镜像 → 重跑 **L5-07/08** 与 **L4-02**
