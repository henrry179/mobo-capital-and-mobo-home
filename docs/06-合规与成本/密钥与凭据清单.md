## 2. 存放规则

```
服务器：/opt/mobo-stack/.env   chmod 600  chown root:root
密码管理器：每个密钥一条，附用途/轮换日期/恢复说明
Git：只允许 .env.example（占位符），不得有真实值
聊天/截图/邮件：禁止
```

### 2.1 `.env` 权限

```bash
chmod 600 /opt/mobo-stack/.env
chown root:root /opt/mobo-stack/.env
ls -l /opt/mobo-stack/.env
```

### 2.2 Git 检查

```bash
git check-ignore -v .env
git grep -nE 'LTAI|ChangeMe_|BEGIN (RSA|OPENSSH) PRIVATE KEY' || true
```

## 3. 生成命令

```bash
# 数据库/应用密码（32 字节 base64）
openssl rand -base64 32

# 十六进制（适合 n8n encryption key）
openssl rand -hex 32

# Caddy Bcrypt
docker run --rm caddy:2.9-alpine caddy hash-password --plaintext '强密码'

# Restic 仓库
# 在 .env 设置 RESTIC_PASSWORD 后：
docker compose exec -T restic-backup restic init
```

> Bcrypt 哈希含 `$`，`.env` 中必须单引号包裹；不要用双引号。

## 4. 轮换步骤

### 4.1 数据库密码

```sql
ALTER ROLE user_archive PASSWORD '新密码';
```

```bash
# 更新 .env 中对应变量
docker compose up -d archive-dashboard restic-backup
# 或重启使用该账号的服务
```

验证：`mobo-cli doctor`、看板、备份。

### 4.2 OSS AK/SK

1. 新建 RAM 子账号/新 AK，授予最小权限。
2. 更新 `.env` 的 `ALIYUN_ACCESS_KEY_ID/ALIYUN_ACCESS_KEY_SECRET`。
3. `docker compose up -d mobobrain-n8n archive-dashboard restic-backup`。
4. 手工上传/备份验证。
5. 禁用旧 AK，观察 24h。

### 4.3 Restic 密码

```bash
docker compose exec -T restic-backup restic key add
# 输入新密码；验证
docker compose exec -T restic-backup restic snapshots
docker compose exec -T restic-backup restic key remove
```

同步更新 `.env` 与密码管理器；**先 add 再 remove**。

### 4.4 n8n 加密密钥

- 不能直接改：已加密的凭证会用旧密钥解密。
- 如必须换：在 n8n 中重新录入所有凭证，或导出/导入并重新加密；先备份 `n8n_data` 与数据库。
- 任何情况下都把原密钥存密码管理器。

### 4.5 Caddy BasicAuth

```bash
docker run --rm caddy:2.9-alpine caddy hash-password --plaintext '新密码'
# 更新 CADDY_ADMIN_PASSWORD_HASH（单引号）
docker compose up -d --force-recreate caddy
```

## 5. 泄露应急

1. **立即禁用**：RAM AK、LLM Key、SSH 密钥、数据库密码。
2. **轮换**：按上面步骤；先加新，再删旧。
3. **排查**：Caddy 日志、n8n 执行、数据库 `pg_stat_activity`、OSS 访问日志。
4. **恢复**：如数据被改，按备份恢复；评估是否需要通知。
5. **复盘**：泄露路径、时间、影响、改进。
