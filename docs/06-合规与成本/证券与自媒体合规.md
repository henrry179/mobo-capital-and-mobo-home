# 证券与自媒体合规

> 适用范围：莫伯资本（MoBoCapital.com）的官网栏目、微信公众号《MoBo's Memo》、雪球、X（Twitter）等对外发布内容；以及数据库中的 `capital` 投研域（论点、策略、交易复盘、净值、孵化里程碑）。
>
> **本文是工程化的风控清单，不构成法律意见。** 涉及具体业务动作（募资、投顾、代客）时必须咨询持牌律师。

## 1. 核心定位（先定性，再写内容）

| 项 | 定位 |
|---|---|
| 主体 | 个人（自然人）自建站点与自媒体，**非持牌机构** |
| 内容性质 | 个人投资方法论笔记、公开市场研究、复盘与项目进展记录 |
| 明确不是 | 证券投资咨询、证券投资顾问、代客理财、公开募集、收益承诺 |
| 收益披露 | 仅展示**历史**净值、R 倍数与回撤，标注"已实现/模拟"，不承诺未来收益 |

> 一旦出现"跟随我的操作""按我的建议买入""帮你管理账户"等表述，即越出本项目边界，必须在发布前拦截。

## 2. 三级可见性对应的对外口径

| 可见性 | 可展示内容 | 禁止内容 |
|---|---|---|
| `PUBLIC` | 方法论、宏观框架、公开市场观察、已脱敏的复盘结论、风险框架 | 具体买卖点位与目标价、未脱敏的净值与持仓、任何收益承诺 |
| `LP_PROSPECT` | 累计 R 乘数、单笔组合净值贡献（bps）、多空净敞口、风控章程 | 第三方可转发的证据链材料（仍需 BasicAuth 保护） |
| `INTERNAL` | 全量实盘底稿、交割单签署链接、基金法律架构文件 | 任何形式的公网暴露；只允许 `/internal/*` + BasicAuth + 审计日志 |

## 3. 境内平台合规要求（微信 / 雪球）

### 3.1 强制脱敏（工程实现）

在提示词层（`workflows/prompts/mobo-capital-synthesis-prompt.md`）与发布前人工复核两层执行：

1. **删除具体买卖指令**：个股买卖方向、目标价、仓位比例、精确入场/止损价。
2. **改写为客观推演**：如"原：买入 300ETF 至 3.85；改：宏观流动性收敛情形下，300ETF 的隐含波动率处于 28% 低分位，具备构建波动率头寸的结构条件"。
3. **禁止绝对收益表述**：删除"必涨""稳赚""翻倍""无风险"等；改为条件句与概率描述。
4. **强制免责声明**：文末固定追加

   > 【风控与合规声明】本文系莫伯个人宏观与量化交易体系的学术复盘笔记，首发于 MoBoCapital.com，不构成任何证券投资建议或收益承诺。市场有风险，决策需独立。

5. **保留可验证性**：可以展示历史 R 倍数、回撤、胜率，但必须标注统计区间与样本量。

### 3.2 平台侧注意事项

| 平台 | 注意点 |
|---|---|
| 微信公众号 | 订阅号可推草稿箱；群发前需在后台人工确认。避免在标题/摘要中出现荐股暗示 |
| 雪球 | 社区对"个股观点"敏感；使用 `$代码$` 话题标签但不写确定性结论；保留免责声明 |
| X（Twitter） | 境外尺度较宽，但仍不得声称受监管、不得提供"付费信号"服务；串推首尾需带免责声明与主站链接 |

## 4. 禁止事项清单（发布前逐条检查）

- [ ] 未出现具体个股/ETF 的买卖指令、目标价、具体仓位比例
- [ ] 未出现收益承诺、绝对化表述、"无风险"字样
- [ ] 未出现"代客""跟单""带单""帮你操作"等表述
- [ ] 未出现募资、基金份额、代销、投顾等金融服务招揽
- [ ] 未泄露 INTERNAL 数据：实盘底稿、持仓明细、交割单、未公开净值曲线
- [ ] 未泄露他人隐私信息（家庭影像、证件、健康数据）
- [ ] 免责声明已按平台格式追加（境内平台强制）
- [ ] 涉及历史业绩时标注了统计区间与"历史"字样
- [ ] 文章 `visibility` 与内容敏感度匹配（`INTERNAL` 不进公域包）

## 6. 基金孵化蓝图相关的额外约束

`capital.fund_incubation_milestones` 与 `fund_governance_docs` 记录的是**个人职业发展计划**，不是对外的基金产品：

- 阶段名称使用"自营交易 / 种子孵化 / 独立基金设立"等中性表述；
- 对外文案不得暗示已设立、已备案或正在募集任何基金产品；
- `visibility` 默认 `PUBLIC` 的里程碑应避免使用"募资""规模""LP 募集"等措辞；
- 真正设立主体前需完成法考、证券从业资格与会计资质，并取得法律意见。

## 7. ICP 与站点命名

- 网站名称避免"基金""投资""理财""量化""金融""证券"等需要前置审批或易被驳回的词；
- 推荐："莫伯资本 — 个人投研笔记与数字档案" / "莫伯之家 — 个人数字档案馆"；
- 备案信息中的"网站服务内容"填"个人博客/学习笔记/个人记录"；
- 详见 [`ICP与域名材料清单.md`](ICP与域名材料清单.md)。

## 8. 数据出境与第三方

| 第三方 | 数据 | 区域 | 措施 |
|---|---|---|---|
| LLM/Embedding API | 文章与复盘正文 | 取决于服务 | 只发送必要片段；`INTERNAL` 与 `VAULT` 数据禁止送入模型 |
| X API | 串推文本 | 境外 | 人工确认后发布；不含持仓与净值明细 |
| 微信开放平台 | 公众号草稿内容 | 境内 | 草稿箱；不含内部数据 |

## 9. 事件响应

若发现已发布内容违规：

1. 立即下架（网站静态页删除文章 JSON 条目并重新导出；平台端删除）。
2. 评估是否造成误导性陈述或利益冲突。
3. 修订提示词与检查清单，归档事故记录。
4. 必要时主动更正并说明。
