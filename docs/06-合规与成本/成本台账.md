# 成本台账

> 币种：人民币（CNY，含税估算）。价格为 2026 年常见区间，**以阿里云控制台实时价格为准**。
> 目标：首年可控制在 ¥3,000–8,000；第二年按实际用量续费。

## 5. 成本公式

```text
月成本 ≈ 服务器 + 系统盘/快照 + OSS 存储 + OSS 请求 + OSS 流量 + LLM + 监控
OSS 存储 = Σ(各层 GB × 单价)
OSS 流量 = 外网下行 GB × 单价
LLM = Σ(input_tokens/1M × 输入单价 + output_tokens/1M × 输出单价)
备份增量 ≈ 每日变更量 × 保留天数 × 压缩率（Restic 去重后更低）
```

## 7. 降本措施

1. **OSS 生命周期**：按 `scan_doc/photo/video/restic` 分层；先确认访问频率。
2. **缩略图**：看板只加载 WebP 缩略图，原片按需签名下载。
3. **Restic 去重**：不要每天全量复制；保留策略不要过长。
4. **n8n 执行记录**：7 天清理，避免数据库膨胀。
5. **日志**：Docker 10MB×3、Caddy 轮转 5 份。
6. **LLM**：先规则过滤/去重，再调用；长文分段摘要；缓存结果。
7. **带宽**：静态资源走 OSS/CDN（如流量大）；内网 Endpoint 免流。
8. **服务器**：监控实际 CPU/内存，避免盲目升配；Swap 兜底。
