# 隐私与数据分类

> 适用：网站 A（公开内容 + 私有知识库/自动化）与网站 B（个人数字档案）。
> 原则：**最小必要、目的限定、默认私有、可删除、可解释。**

## 1. 数据分类

| 级别 | 定义 | 示例 | 存储/访问 |
|---|---|---|---|
| `PUBLIC` | 已决定公开 | 公开文章、公开图床图片 | OSS 公开 Bucket / `www` |
| `RESTRICTED` | 可向特定人分享 | 读书笔记摘录、非敏感项目复盘 | 私有库，需认证 |
| `PRIVATE` | 个人默认隐私 | 时间线、阅读/运动记录、体重、睡眠 | `db_archive`，仅本人 |
| `VAULT` | 高敏，泄露危害大 | 身份证、医疗报告、合同、财务凭证 | 私有 OSS + 加密；禁止公网直链 |

### 1.1 字段映射

| 数据 | 表/位置 | 级别 | 保留 |
|---|---|---|---|
| 书名、作者、评分、摘要 | `archive.reading_items` | `RESTRICTED`/`PRIVATE` | 长期 |
| 阅读会话、摘录、批注 | `archive.reading_logs` | `PRIVATE` | 长期 |
| 运动记录、心率、配速 | `archive.fitness_workouts` | `PRIVATE` | 长期 |
| 体重、体脂、睡眠、HRV | `archive.fitness_biometrics` | `PRIVATE` | 长期 |
| 复盘、KPI、行动项 | `archive.project_retrospectives` | `PRIVATE` | 长期 |
| 照片/视频/扫描件 | `archive.archive_assets` + OSS | `PRIVATE`/`VAULT` | 按资产策略 |
| 证件/医疗/合同 | 私有 OSS `documents/` | `VAULT` | 按法规/个人决定 |
| 公开文章 | `intel.articles_vault` + 思源 + `www` | `PUBLIC` | 长期 |
| 采集运行/LLM 用量 | `intel.ingestion_runs` / `llm_usage` | `RESTRICTED` | 180 天 |
| n8n 执行记录 | `n8n.execution_entity` | `RESTRICTED` | 7 天 |
| Caddy 访问日志 | `deploy/volumes/caddy_logs` | `RESTRICTED` | 30 天 |
| 备份 | Restic/OSS | 同源数据 | 7 日/4 周/6 月 |

## 2. 处理目的与合法性基础

| 目的 | 数据 | 合法性基础（中国《个人信息保护法》） |
|---|---|---|
| 个人知识管理 | 笔记、阅读、复盘 | 个人/家庭事务豁免（第 72 条）或同意 |
| 个人健康记录 | 运动、体重、睡眠、心率 | 单独同意（敏感个人信息） |
| 数字资产归档 | 照片、证件、合同 | 同意/履行义务 |
| 内容采集与摘要 | 公开文章、URL | 公开来源、合理使用；尊重版权 |
| 安全审计 | 访问日志、登录失败 | 安全保护必要 |
| 备份恢复 | 全量数据 | 安全保护必要 |

> 本项目是个人自用系统，不面向公众提供注册/社交/交易；如未来开放，需要重新评估隐私政策、同意机制与备案。

## 3. 最小化与脱敏

- 公开站只发布经过筛选的内容；不发布原始笔记、附件、个人信息。
- 公开图床只放缩略图/公开图片；原片/证件放私有 Bucket。
- LLM 调用只发送必要文本；不发送身份证号、银行卡、医疗报告全文。
- n8n 工作流日志不打印完整凭证/正文。
- 看板默认不展示 `VAULT` 资产；仅显示元数据。
- 导出/分享前检查 EXIF/GPS、文件名、二维码。

## 4. 保留与删除

| 数据 | 保留 | 删除方式 |
|---|---|---|
| 业务表 | 长期 | 软删除资产；业务表硬删除前确认备份 |
| 资产原片 | 按个人策略 | 软删除 + 引用计数 0 + OSS 对象删除 |
| n8n 执行 | 7 天 | `EXECUTIONS_DATA_MAX_AGE=168` |
| Caddy 日志 | 30 天 | 轮转/truncate |
| 备份 | 7 日/4 周/6 月 | Restic `forget --prune` |
| LLM 用量 | 180 天 | 定期归档/删除 |
| 采集运行 | 180 天 | 定期归档/删除 |

**删除请求流程（本人）**：

1. 确认资产 ID/表/时间范围。
2. 检查引用（阅读封面、运动轨迹、时间线）。
3. 软删除 `deleted_at`；引用为 0 后删除 OSS 对象。
4. 清理备份中的对应对象：Restic 保留策略到期后自然删除；如需立即删除，重建仓库/使用 `restic forget --prune`（影响其他快照，谨慎）。
5. 记录删除日志（不含内容）。

## 5. 第三方与跨境

| 第三方 | 数据 | 区域 | 说明 |
|---|---|---|---|
| 阿里云 OSS | 文件、备份 | 中国大陆 | 同地域；私有 Bucket |
| LLM/Embedding 提供方 | 文章/笔记文本 | 取决于服务 | 优先选境内/可关闭训练的 API |
| RSS/网站 | 公开文章 | 全球 | 只采集公开内容 |
| 阿里云监控/拨测 | 访问状态 | 中国大陆 | 不传正文 |
| UptimeRobot（如用） | URL/状态码 | 境外 | 不传凭证/正文；可改用阿里云拨测 |

- 不使用境外服务处理 `VAULT` 数据。
- 如使用境外 LLM，先脱敏，避免传输身份证/医疗/财务原文。
- 在隐私政策/内部记录中列明第三方类别、目的、大致区域。

## 6. 安全措施

- HTTPS、BasicAuth、`noindex`、私有 Bucket、签名 URL。
- 数据库最小权限；看板只读。
- `.env` 600；密钥密码管理器。
- 备份 Restic 加密；恢复演练。
- 日志脱敏；不记录密码/token。
- 设备全盘加密；离开锁屏。

## 7. 数据主体权利（本人/未来用户）

| 权利 | 实现 |
|---|---|
| 知情 | 本文档 + 隐私政策（如公开） |
| 访问 | 看板/CLI 查询；导出 JSON/CSV |
| 更正 | CLI/看板/直接 SQL（谨慎） |
| 删除 | 软删除 + OSS 清理 + 备份到期 |
| 可携带 | `pg_dump` + 文件导出 |
| 撤回同意 | 停止采集/删除数据；不影响已合法处理 |

## 8. 泄露响应

1. 立即限制入口/禁用密钥/停工作流。
2. 评估泄露数据类别、数量、影响。
3. 保留日志，修补漏洞。
4. 如涉及敏感个人信息，评估是否需向监管部门/个人通知。
5. 记录事件与改进项。

## 9. 隐私检查清单

- [ ] 公开站不含个人信息/原始附件。
- [ ] 私有 Bucket 阻止公共访问；签名 URL 短有效期。
- [ ] `VAULT` 数据未进入 LLM/公开站。
- [ ] 看板不展示高敏资产内容。
- [ ] 日志不含密码/token/正文。
- [ ] 备份加密；恢复演练通过。
- [ ] 第三方清单与区域已记录。
- [ ] 删除流程可执行。
