# ICP 与域名材料清单

> 本文是准备清单，不构成法律意见。以阿里云备案系统和各省通信管理局最新要求为准。
> **大陆服务器 + 域名对外提供网站服务，必须完成 ICP 备案；未备案不要开放 80/443。**

## 1. 适用范围

| 站点 | 域名 | 是否需要备案 | 说明 |
|---|---|---|---|
| 网站 A 主站 | `mobocapital.com` / `www` | 是 | 莫伯资本：公开投研栏目 + 私域内网驾驶舱 |
| 网站 A 知识库 | `kb.mobocapital.com` | 是 | 同一主域下的子域，通常随主域备案 |
| 网站 A 自动化 | `n8n.mobocapital.com` | 是 | 后台也属于网站服务 |
| 网站 B 主站 | `mobohome.com` / `www` | 是 | 莫伯之家：个人数字档案馆 |
| 网站 B 实验室 | `lab.mobohome.com` | 是 | 同上 |
| 静态操作台 | `admin.mobocapital.com` | 是 | 同上 |

> **双主域需要两次（或一次主体下两个站点）备案**。两个主域都需完成实名认证，持有者与备案主体一致。
> 若使用香港/海外服务器，不适用大陆 ICP，但访问速度、合规与数据出境问题需另行评估。本项目基线为大陆阿里云。

### 1.1 名称敏感词（重要）

网站名称与"网站服务内容"中**避免**出现：基金、投资、理财、量化、金融、证券、资产管理、私募、投顾、理财顾问、财富管理、交易所等易触发前置审批或被驳回的词。

推荐写法：

| 字段 | 推荐 | 避免 |
|---|---|---|
| 网站名称 | 莫伯资本 — 个人投研笔记 | 莫伯资本基金 / 莫伯量化投资 |
| 网站 B 名称 | 莫伯之家 — 个人数字档案馆 | 莫伯家庭金融档案 |
| 服务内容 | 个人博客 / 学习笔记 / 个人记录 | 投资资讯 / 金融服务 / 基金 |

## 2. 主体材料

### 2.1 个人备案

- [ ] 身份证正反面照片/扫描件（清晰、四角完整）。
- [ ] 本人手机号（接收验证码，需实名）。
- [ ] 常用邮箱。
- [ ] 紧急联系人姓名/电话。
- [ ] 人脸核验（阿里云 App/小程序）。
- [ ] 手写承诺书（按省份模板）。
- [ ] 域名证书（域名注册商下载）。
- [ ] 服务器/轻量应用服务器购买凭证（通常要求剩余时长 ≥3 个月）。

### 2.2 企业备案（如适用）

- [ ] 营业执照副本。
- [ ] 法定代表人身份证。
- [ ] 网站负责人身份证。
- [ ] 授权书（负责人非法人时）。
- [ ] 公章。
- [ ] 企业实名认证的阿里云账号。
- [ ] 域名持有者与主体一致（或提供授权）。

## 3. 域名要求

- [ ] 域名已完成 **实名认证**，且持有者与备案主体一致。
- [ ] 域名未过期，建议一次注册 3 年以上。
- [ ] 域名后缀在工信部许可名单内（`.com`/`.cn`/`.net` 等）。
- [ ] 解析记录：`www`、`kb`、`n8n`、`archive`、`admin` 指向备案服务器。
- [ ] 备案期间可先不解析，或解析到备案专用提示页；不要直接提供完整服务。
- [ ] 域名证书与备案系统填写的主域名一致。

## 4. 服务器要求

- [ ] 阿里云大陆地域（如华东1/华北2）。
- [ ] 购买时长 ≥3 个月（部分省份要求更长）。
- [ ] 实例 ID、公网 IP、地域。
- [ ] 安全组已放行 80/443（备案审核可能访问）。
- [ ] 服务器上不要运行未备案的其他网站。

## 5. 网站信息填写

### 5.1 网站 A（MoBoBrain）

| 项 | 建议填写 |
|---|---|
| 网站名称 | 莫伯读书与技术札记（不要用“XX门户/XX新闻/XX在线”等敏感词） |
| 网站服务内容 | 个人博客/知识分享 |
| 网站语言 | 中文 |
| 前置审批 | 无（不涉及新闻/出版/教育/医疗等） |
| 备注 | 个人学习笔记、技术实践记录，非经营性 |

### 5.2 网站 B（个人数字档案）

| 项 | 建议填写 |
|---|---|
| 网站名称 | 莫伯个人数字档案 |
| 网站服务内容 | 个人记录/工具（仅本人使用） |
| 访问方式 | 强认证，不对外开放注册 |
| 备注 | 个人时间线、阅读/运动记录；无公众交互 |

> 两个网站可作为一个主体下的两个网站备案，也可按接入商要求合并/拆分。以阿里云备案系统提示为准。

## 6. 审核流程与时间

```text
准备材料 → 阿里云初审（1–2 个工作日）
        → 短信核验/人脸核验
        → 管局审核（一般 5–20 个工作日，各省不同）
        → 备案号下发
        → 网站底部展示备案号并链接工信部
        → 30 日内完成公安联网备案（如适用）
```

- 审核期间保持手机畅通；管局可能电话核验。
- 退回补正常见原因：域名持有者不一致、网站名称敏感、服务器时长不足、照片模糊、承诺书未手写。
- 备案号格式如 `浙ICP备2026XXXXXX号-1`；网站 B 可能是 `-2`。

## 7. 上线后合规

- [ ] 页脚展示备案号，链接 `https://beian.miit.gov.cn/`。
- [ ] 公安联网备案（如当地要求），页脚展示公安备案号。
- [ ] 不提供未备案的论坛/评论/直播/新闻等服务。
- [ ] 不发布违法违规内容；公开站有内容审核流程。
- [ ] 每年做备案年度审核（如要求）。
- [ ] 主体/域名/服务器变更时及时更新备案。

## 8. 常见问题

| 问题 | 处理 |
|---|---|
| 域名在其他云/注册商 | 需在阿里云接入备案，或转入阿里云 |
| 服务器只剩 1 个月 | 续费到 ≥3 个月再提交 |
| 网站名称被拒 | 改用“个人博客/学习笔记”等非敏感名称 |
| 子域是否要单独备案 | 同一主域下通常随主域；以管局/接入商为准 |
| 私有站点是否要备案 | 只要公网可访问就需要；纯内网不需要 |
| 备案期间能否访问 | 可解析到备案提示页；不要提供完整服务 |
| 换服务器 | 办理接入变更，不要直接切走 |

## 9. 材料归档

建议在密码管理器/加密盘保存：

```text
compliance/
├─ icp/
│  ├─ 主体证件/
│  ├─ 域名证书/
│  ├─ 服务器凭证/
│  ├─ 备案订单号与截图/
│  └─ 备案号/公安备案号
├─ privacy/
│  ├─ 隐私政策版本
│  └─ 数据处理记录
└─ cost/
   └─ 发票/账单
```

> 证件照片属于高敏数据，不要放 Git、网盘公开链接或聊天记录。
